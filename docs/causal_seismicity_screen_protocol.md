## 1. 通俗说明

已经验证过的 75 km KDE 相当于一张“长期地震多发区底图”。本阶段只问一个更直接的问题：

> 在这张长期底图上加入最近 30 天已经发生且当时可用的 M4+ 地震，能否用同样
> 600,000 平方公里报警面积，多覆盖未来 M5–6 地震？

为了确认提升来自“近期”，还要与“再前一个 30 天”的同结构模型比较。只比较这三版：

- `S0`：长期 75 km KDE；
- `S1`：长期 KDE + 最近 30 天地震 KDE；
- `SP`：长期 KDE + 再前一个 30 天地震 KDE。

若 `S1` 不能同时超过 `S0` 和 `SP`，本路线停止，不改成 60、90、365 天或完整 Hawkes 再试。
这个选择有意接受较高的假阴性，换取一次可解释、可快速证伪的科学检验。

三版共享同一个 M5–6 事件率，近期 M4+ KDE 也都归一到 1，所以本阶段主要检验“未来地震更可能落
在哪里”，不检验“未来总数会不会增加”或“具体哪一天会发生”。地图只能叫相对强度/排序图，
不能叫完整时空概率预测。

必须诚实说明：本阶段的 2022–2023 日历已经在 Stage 2R 用于背景模型开发和 75 km 带宽选择。
因此它只是“Stage 2S 新增权重和候选图按时间因果隔离”的复用开发筛查，不是全局目标盲、独立
模型选择或新验证。真正独立证据只能来自以后新封存的前瞻时段或满足所有前置门的锁定测试。

## 3. 模型的精确定义

### 3.1 长期背景 `S0`

`S0` 精确复现 `fold_4`：

- 截止 `2019-12-31T16:00:00Z`；
- 先用截止前全部目录震级重建并核验支持域，再取支持域内 `M>=4.0` 训练；
- 75 km 等面积 Gaussian KDE；
- 在同一冻结支持域用 12.5 km 求积归一到 1；
- 禁止重选带宽、Mc、支持域或使用 `final_validation`；
- 公开 registry 只作身份核对，不是推理模型。

运行时还必须逐字段核对 `support_id=local-support-788851371baf0e3b`、`common_mc=4.0`、
500/1,000 km 支持格、历史事件 24,173 个及其冻结哈希、投影几何哈希
`c5074034...b7231`、保留面积 `9,415,305.754432771 km²` 和保留率 1.0。任一不符即无效。

### 3.2 最近与前期窗口

起报时刻为 `T`。

最近窗口 `R_T` 只含：

```text
T-30d < origin_time_utc <= T
available_at <= T
M >= 4.0
研究区和冻结支持域内
```

前期对照 `RP_T` 只含：

```text
T-60d < origin_time_utc <= T-30d
available_at <= T-30d
M >= 4.0
研究区和冻结支持域内
```

两窗长度相同，事件等权，空间带宽同为 75 km，分别在同一支持域归一。Gaussian 带宽就是二维
核的标准差。原始密度是各事件二维 Gaussian 核的算术平均；归一常数唯一使用原点固定的 12.5 km
支持域裁剪格，在每个裁剪格代表点计算密度并乘精确裁剪面积后用 `math.fsum` 求和。

事件评分和权重拟合都在事件投影后的真实坐标上计算连续归一 KDE，使用稳定 `logsumexp`。原始
KDE 明确采用核的算术平均，因此稳定 log 密度必须同时包含 `-log(source_event_count)`、
`-log(2*pi*b²)` 和 `-log(同一 mean-KDE 归一常数)`；不得把核总和与均值的归一约定混用。

坐标权限分三类：当时已可用的 M4+ 历史源坐标可在起报时成为 predictor 核中心；fit M5–6 坐标
只可在该折 fit 截止后、且上一折已封印后用于 alpha 连续密度拟合；只有 assessment target 坐标与
memberships 必须等到三折总 `master prediction seal` 后才开放。任何 target 坐标都不能生成或加密格网、
候选、区域、窗口、带宽或改变参数。不得查 25 km 所在格、插值或把格质量除面积来代替连续密度，
也不得做密度截断。若某窗没有事件，该分量精确退化为 `S0`。

### 3.3 两个混合模型

每折分别拟合两个标量：

```text
S1 = (1-alpha_R_fold) * S0 + alpha_R_fold * R_T
SP = (1-alpha_P_fold) * S0 + alpha_P_fold * RP_T
```

`alpha_R_fold` 和 `alpha_P_fold` 都在 `[0,1]`，只用该折 assessment 之前的非重叠 7 天
fit exposures。每个 fit 事件唯一绑定 `(T,T+7d]` 的 issue map；预测历史只含
`origin_time_utc<=T` 且 `available_at<=T` 的源事件。fit 标签必须是支持域内、去重的 M5–6
事件，并在该折冻结 fit 截止前已经可用。assessment 不得参与。

目标函数和导数唯一为：

```text
L(a)  = sum_i log((1-a)*q0_i + a*qX_i)
L'(a) = sum_i (qX_i-q0_i) / ((1-a)*q0_i + a*qX_i)
L''(a)= -sum_i ((qX_i-q0_i) / ((1-a)*q0_i + a*qX_i))^2
```

求解规则唯一固定：

1. 导数按 origin time、event ID 顺序用 `math.fsum` 求平均；在 0 处不大于 `+1e-12` 时取 0；
2. 导数在 1 处不小于 `-1e-12` 时取 1；
3. 否则固定做 64 次二分；
4. `max(abs(qX/q0-1))<=1e-12` 时视为完全平坦并取 0；
5. 二分中导数大于 0 更新左端，否则更新右端，最后取两端均值；
6. 非有限、非正密度、非正归一常数或不满足凹性时整轮无效，禁止密度 floor、网格搜索和四舍五入。

判定顺序固定为：无 fit 事件→非有限/非正→flat→0 端导数→1 端导数→二分；两个端点容差条件
同时成立时按 0 端优先取 0。混合 log 密度在 `a=0/1` 直接取端点，内部使用
`logaddexp(log1p(-a)+logq0, log(a)+logqX)`。

每折一个权重，共享该折 7/30/90 天，禁止按窗口另拟合。

## 4. 共同率与补偿项

每折只用该折 7 天 fit exposures 内、支持域中的 `M5_6` 事件数除以总曝光天数得到共同日率
`r_f`。事件必须去重、唯一绑定 7 天 exposure，并在该折 fit 截止前可用。`S0/S1/SP` 严格
共享该率，禁止使用 M4+ 源事件率或为候选分别拟率；事件数为 0、日率非正或非有限时证据不足。

三版空间质量均在同一域积分为 1，且预测图在 `T` 时冻结，不在未来窗口内继续衰减。因此任意
单个起报 issue 的窗口 `h` 总期望数都是：

```text
r_f * h
```

一个 `fold × horizon` 有多次互斥 issue 时，其总补偿项必须再对该格全部 issue 求和。
12.5 km 归一质量按对齐的 row/column 聚合到 25 km 父格，作为报警和区域补偿的唯一质量。
直接在 25/50 km 代表点计算的质量只用于 25↔12.5 和 50↔25 收敛核验，不用于事件评分或报警。
所有 operational 质量和的绝对误差不得超过 `1e-12`；收敛超过预登记的 2% 总量或 5% L1
阈值时整轮无效。

候选与对照的全域补偿差理论上为 0，但代码必须用聚合质量独立数值复算；绝对误差超过 `1e-10`
时无效。
这条最小模型不需要 composite-midpoint 时间积分，也不能偷偷改成窗口内继续衰减的另一模型。

## 7. 指标、Bootstrap 和唯一通过门

每个 `fold × horizon` 同时计算信息增益和固定面积严格召回。固定 horizon 的点估计是该
horizon 三折 cell 的算术平均；fold macro 是该折三 horizon cell 的算术平均；overall macro
是三折 macro 的算术平均。每个九宫格权重均为 `1/9`。

两项确认比较是：

1. `S1-S0`；
2. `S1-SP`。

使用 2,000 次配对物理事件块 Bootstrap。同一 `event_id` 携带其全部折/窗口 membership，在
`fold × 7/30/90 membership signature × supported_IG_bit` 内有放回抽样；增加 support bit
可保证信息增益和全区召回使用不同分母时不会随机抽空支持域样本。同一 multiplicity 同时用于三版
模型和全部指标。

PCG64 的 UTF-8 namespace、128-bit SHA256 entropy、stratum/event/draw 顺序和唯一
`rng.integers` 调用已经逐字冻结；空 stratum 不调用 RNG。Bootstrap 内不重拟合模型、率、权重
或报警区；失败复制不得删除、替换或换种子。

三位 membership 文本顺序固定为 `b7,b30,b90`，按拼接后的二进制整数升序；因此 `001` 只表示
90 天 membership。时间相同时 event/zone/component ID 均按无符号 UTF-8 bytes 升序。

这些区间只表示在固定日历、已观察分层大小和已拟合折模型下，以物理事件为重采样单位的条件稳定性；
它不把整个震群作为抽样块，因此不能解释为“地震序列彼此独立”或新的独立验证。结果必须同时报告
震群 component 数和 event resampling unit 数，并用下述震群去除诊断限制结论范围。

信息增益和召回各自组成一个两成员 family。使用 Bonferroni 双侧家族 95% 同时区间，每项取
`1.25%–98.75%` percentile；分位数固定为 NumPy `linear` 定义。普通 95% 区间只作诊断。

`G1-T` 通过必须同时满足：

- 7、30、90 天的 `S1-S0` 和 `S1-SP` 信息增益点估计均为正；
- 两项比较都至少 2/3 折宏信息增益为正，折中位数为正；
- 两项总体宏信息增益的家族同时下界均大于 0；
- 两项比较都至少 2/3 折宏召回增益为正，折中位宏召回增益为正；
- `S1-S0` 的 600,000 平方公里宏召回至少提高 5 个百分点，且同时下界大于 0；
- `S1-SP` 的同面积宏召回点估计和同时下界均大于 0；
- 跨区、去最大贡献区和 1/7 天目录延迟敏感性通过。

`SP` 是单个确定性过去对照，不是随机置乱；禁止报告 permutation p 值。
另报告 `SP-S0` 点估计作为解释性结果，但它不进入同时区间或通过门：

- `S1>S0` 但不胜 `SP`：只说明空间聚集有用，未证明“最近 30 天”更新更有用；
- `SP>S0`：只提示较旧窗口值得以后另立新协议，不授权本次改窗重试；
- 两个增量都不胜 `S0`：当前固定 30 天方案不获支持。

## 8. 跨区、震群和目录延迟

从第一版目标盲输入接口就必须同时返回：

```text
query_grid
construction_zone_id_by_cell_id
```

区域映射必须覆盖 15,697 个固定格和 39 个非空区域，只返回编号，不返回坐标或 geometry；
`query_grid` 则必须携带前述本地目标无关坐标和面积。若 code tag 后、目标读取前不能把二者合法
同时提供，本阶段立即停止，不能重演 `0.4.4` 的丢映射问题。

对 `S1-S0` 和 `S1-SP` 分别做区域门。对任一对比 `A-B`、区域 `z`、折窗格 `f,h`：

```text
G[z,f,h] =
  (sum_{e in E[z,f,h]} log(q[A,T(e)](e)/q[B,T(e)](e))
   - sum_{T in J[f,h]} r[f]*h*(M[A,T,z]-M[B,T,z]))
  / n_supported[f,h]
```

即区域补偿必须逐个 assessment issue 求和，括号内是该 issue 候选与比较器在该区的 operational
质量差；不能只算一个 issue。召回贡献是该区全区 hit difference 除以原全区分母。
两者都先逐格、后按 `1/9` 相加，因此 39 区贡献之和必须分别闭合到总体宏指标，绝对误差不超过
`1e-10`。

两个对比、两个指标都必须至少有两个“有该指标事件且贡献大于 `1e-12`”的区域。零事件区仍报告
并参与 39 区可加闭合，但不能充当跨区正证据。对每个对比、每个指标只在“有事件且正贡献”的集合
中按贡献最大、zone ID UTF-8 bytes 升序并列规则选“最大区”，用
`总体宏指标 - 该区可加贡献` 做固定原分母的 leave-one-region-out；不重训、不重排、不改分母。
两项残差都必须大于 `1e-12`。全部 39 区都报告，因为无事件区仍可能有补偿贡献。

主分析保留所有震群，因为震群续发本身可能有真实预测价值。诊断用 WGS84 geodesic，按“时间差
不超过 2,592,000 秒且距离不超过 75,000 米有边”的固定无向连通分量划分。对两个对比分别按原
九宫格分母计算严格可加的事件 log 和 hit difference 贡献。每个对比分别选择最大 IG-gain 分量
和最大 recall-gain 分量，另保留最大事件数分量；三类都逐一用固定原分母 leave-out，不重训或
改分母。sequence event 项不分摊全域补偿；残差从包含独立全域补偿的主宏指标减去所选 event
分量，且“所有 sequence event 项 + 未分配全域补偿”必须闭合到主宏指标。总体增益不大于
`1e-12` 时份额记空但原值仍报告。

连通分量可能通过链式边延伸得很远，所以还必须报告总时间跨度、最大两两距离和事件数。若去除后
任一所需对比的增益不再大于 `1e-12`，只能把结论限定为“震群相关续发有效”，不能称为广泛区域
提升；该诊断不删除主结果，也不改变主门的 pass/fail。

原目录没有真实发布时间，`available_at=origin_time` 是乐观假设。必须分别原样重跑额外 1 天
和 7 天 predictor feed 延迟，不能择优；原始 30 天区间边界不移动，eligibility 是固定 origin
区间与延迟 available-at 条件的交集。只改变 R/RP 源历史并用对应 delayed fit map 重拟两个
alpha，`S0`、目标、日历、共同率、面积和主分母不变。

每个延迟下 `S1-S0`、`S1-SP` 的总体宏信息增益和同面积召回增益都必须大于 `1e-12`。任一小于

   在首个目录字节前认领唯一 target read；receipt 一旦存在，即使后续失败也视为 attempt 已消费；

6. 同一目录 bytes 打开后，先用全震级重建 fold4 支持并逐字段核对冻结 manifest；随后严格按折
   `1→2→3` 执行。每折先只开放该折冻结 fit view，拟合 primary/1 日/7 日延迟权重和共同率，
   在首个 assessment issue 前写不可改写的 `fold fit receipt`；

   issue 写 `O_EXCL issue prediction seal`；末尾写 `fold prediction seal`。后一折 fit view 只有
   在前一折封印后才可开放。同一物理事件若后来成为合法历史或后一折 fit 标签，只能经对应受限
   角色接口使用，禁止携带它先前的 assessment membership、命中或成绩；
8. 三折完成后写绑定三个 fold seal 的 `master prediction seal`；在此之前不得构造、暴露或评分
