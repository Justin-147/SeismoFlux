# 95%支持门与震级类型：影响审计及继续决定

日期：2026-09-02。审计起点：`173e9f140ffe60332eba912401fa18770bbfd636`。

## 1. 先说结论

**不需要推倒重跑。95%门挡住了一项尚未出成绩的试验；Ms说明补全了语义，没有改变已算出的成绩。**

已有最清楚的地点信号仍然是：在2000—2019四段历史外推中，同样圈出约60万km²，区域常率命中
32/147个未来Ms5–6独立震序，长期地震分布命中46/147，长期分布加最近30天活动命中54/147。
这是开发期线索，最好候选仍漏掉93个；不是整个项目完成，也不是最终预测保证。

需要纠正的是先前把“许多稀疏地区不能可靠估计Mc”过度解释成“全国试验不能继续”。这里的Mc是
一个地区能够较完整记录到的最低震级。当地历史地震少时，估不准Mc不等于当地数据无用，更不应
让别的地区也停止研究。

本次不改历史结果，只新增一个小型输入对照，直接看这些处理是否影响预测。

## 3. 两代95%其实不是同一种口径

旧G1-LS把“样本足以估Mc且Mc不高”和“样本少、暂时无法估Mc”都保留，只排除确定Mc过高的格。
C1的面积门只计第一类，把第二类也排除在支持面积分子之外。可是C1的主训练方案又明确允许第二类
继续使用，并附Mc4假设。这造成了“训练方案允许保留未知地区，全国面积门却先把训练叫停”的矛盾。

| 目录截止年 | 可估且Mc≤4的面积 | 样本稀疏、无法判断的面积 | 确定Mc>4的面积 |
| ---: | ---: | ---: | ---: |
| 1984 | 51.15% | 48.85% | 0.00% |
| 1989 | 61.77% | 28.36% | 9.87% |
| 1994 | 61.77% | 28.36% | 9.87% |
| 1999 | 73.97% | 26.03% | 0.00% |
| 2004 | 78.86% | 18.48% | 2.66% |
| 2009 | 83.78% | 16.22% | 0.00% |
| 2014 | 88.55% | 11.17% | 0.28% |

这些是诊断类别的面积比例，不是“全国目录只完整了51%—89%”。也不能把支持面积比例当成报警
面积：预测比较仍只圈约60万km²，绝不是80%或95%的全国面积。

直接用已有16个节点重分类即可回答80%的问题，无须重估Mc：

- 95%：0/16节点，0/4外折起点达到；
- 80%：3/16节点，2/4外折起点达到；
- 达到80%的节点是`C_DEV_2010_2014__OUTER`、`C_DEV_2015_2019__I3`、
  `C_DEV_2015_2019__OUTER`；
- 若继续要求所有节点都达到，80%仍会叫停。因此不应仅把一个缺少普适依据的硬门换成另一个。

今后分别报告支持/未知/高Mc比例及结果差异，把局地质量看作需要检验的假设，不再全国一票否决。
95%置信区间、Mc拟合优度或ETAS分枝率上限不是本问题，不能一并改为80%。

这样既能看“同一个模型换输入后变多少”，也能在每种处理内部用相同数据比较L2/L3与L1，以及近期

后续C2的年代/来源面板、平滑尺度、时间衰减和ridge组合保持有限、分问题比较，不与两种掩膜做

### 方法来源与假设边界

这次不发明新的Mc估计器，复用已经过经典方法复审的C1诊断。国内
[徐伟进、高孟潭（2014）](https://html.rhhz.net/dqwlxb/2014-9-2802.htm)分别研究仪器目录与历史目录、
不同地区和年代的完整性，说明这些差异需要区分处理，不能仅凭一个全国面积比例决定数据是否有用。
该文没有为本项目提供“全国支持面积必须95%”的依据，也不能当成对用户两份目录逐事件质量的担保。

C1采用的MAXC及完整性不确定性参照已记录于旧方法复审：Wiemer与Wyss（2000，
DOI `10.1785/0119990114`）、Woessner与Wiemer（2005，DOI `10.1785/0120040007`）。
500/1000km格、200事件以及A/B未知格处理均应被称为本项目待检验的研究选择，不是经典文献规定的
唯一正确标准。C2A保留这些选择，唯独取消全国停止门，直接测量它们对预测的影响。
