# S1-C2B：目录覆盖与有限位置模型比较

## 1. 这一步要回答什么

已经结束的C2A说明：在现有模型中直接删去完整性较差或未知地区的训练地震，没有带来稳定提高。
现在不再修改95%门、Mc方法或旧成绩。新问题是：**充分保留可用历史后，换一种空间尺度、近期信息
表示或组合方式，能否在同样报警面积下多找出独立震区？**

这是一项有限开发比较，不是比赛，也不是最后的独立检验。已有C0和C2A结果已经看过；C2B预测和
成绩尚未生成。机器可执行方案为`configs/multitask_s1_c2b_catalog_models.yaml`。先完成必要检查、
协议验收和推送，再实现和运行；四折预测保存完毕后统一评价。C2B完成即进入S2多数据增量，不无限
延长目录模型研究。小幅、特定时限或特定震级的可信增益照样保留，不要求每项都显著。

## 2. 采用哪些既有科学方法

| 科学问题 | 文献依据 | 本轮具体采用与边界 |
| --- | --- | --- |
| 不同年代、大小震目录能否等同看待 | 许卫进、高孟潭（2014），中国历史与仪器目录分区讨论 | 保留1970全源、1980小震来源和1950大震来源三个训练面板；年代是保守研究选择，不是本机文件已完整的证明 |
| 过去地震能否指示未来热点 | Helmstetter、Kagan、Jackson（2007），平滑地震活动预测 | 同一75 km高斯核作数据面板的共同模型；不声称复现其全部去丛集流程 |
| 热点空间尺度是否应组合 | Helmstetter、Werner（2012），时空自适应核 | 以25/75/150 km有限核组合检验尺度信息；这不是其自适应邻居算法的原样复现 |
| 近期事件的先后关系是否有用 | Helmstetter、Werner（2014），空间—时间核预测 | 使用近一年事件的相对年龄权重；半衰期是本项目预先列明的有限候选，不冒称文献给出的中国最优值 |
| 多种空间线索是否互补 | Berman、Turner（1992）点过程似然；Bayona等的WHEEL/GEAR混合研究 | 用低维带L2惩罚的条件空间对数线性模型；不重新拟合ETAS，不引入异常或构造特征，不声称复现WHEEL |

主要原始来源：
[中国目录与活动率研究](https://html.rhhz.net/dqwlxb/2014-9-2802.htm)、
[2007平滑地震活动预测](https://central.scec.org/publication/983)、
[2012自适应核](https://central.scec.org/publication/1667)、
[2014时空核](https://central.scec.org/publication/1765)、
[1992点过程似然](https://academic.oup.com/jrsssc/article/41/1/31/6990343)、
[2021混合地震活动预测](https://academic.oup.com/gji/article/224/3/1945/5996192)。

文献支持方法类别和比较动机，不提供任何本项目已经改善预测的证据。具体候选是透明的简化研究设计。
本轮不加新的文献门或昂贵模型；有无价值由紧接着的历史预测比较回答。

## 5. 九个有限位置模型及其输出

所有空间核使用相同投影坐标、25 km格网和真实裁切格面积。每个空间分量先在全国全域归一化，
再混合；不缩小困难地区、不新增震中定制网格。输出为全国格上的相对空间质量/密度及排序，
不是某处必发地震的绝对概率，也不独立输出发震次数或震级分布。

| 模型 | 做法 | 要分离的贡献 |
| --- | --- | --- |
| D0/D1/D2 K75（3个） | 各训练面板均用固定75 km长期高斯核 | 换训练资料的整体效果，模型不变 |
| D0/D1 R30（2个） | 0.75长期K75＋0.25同面板近30天K75 | 相同近期方法下换资料；另以D0 K75比较近期贡献 |
| D0 MULTISCALE（1个） | 25/75/150 km核的四个固定权重候选，在内层选择 | 窄、宽热点的组合是否优于固定K75 |
| D0 AGE_WEIGHTED（1个） | 近365天事件按相对年龄加权，与长期K75混合，内层选参数 | 近期事件的先后信息是否比硬截30天更有用 |
| D0 RIDGE_CORE / RIDGE_M5（2个） | 学习三种目录空间特征；第二个只多一项D2大震历史特征 | 可解释组合及大震历史特征的增量 |

多尺度权重按25/75/150 km顺序为`(0,1,0)、(.5,.5,0)、(1/3,1/3,1/3)、(0,.5,.5)`。
平分时先保留K75，再宽核、均衡核、窄核；没有全国支持门。

年龄权重为`exp(-ln(2)×事件距起报天数/半衰期)`，半衰期7/30/90天，空间核75 km；近期权重alpha
为0/.25/.5/.75，alpha=0只算一个K75候选，共10个候选。平分时较小alpha优先，再较长半衰期。
**这是近期事件相对年龄加权的位置排序，不是发震率衰减模型**：归一化后，没有新事件时共同衰减
会抵消，固定alpha不会自动随安静期变小。这个简化局限如实记录，本轮不增加触发率或Omori参数。
近期窗为空时直接等于同面板长期K75，不能删掉空期。

ridge以固定D0 K75为基底，`log q_j = log p75_j + X_j beta - logsumexp(...)`，无截距、无次数项。
三特征分别为`log(K25/K75)、log(K150/K75)、log(E30_365/K75)`；第四特征为`log(D2_K75/K75)`。
这里E30_365是近365天内半衰期30天的同一年龄加权核，不另选参数。各特征是有限log质量之差，
格面积因素抵消。加入第四特征与不加入的模型必须配对，不能只把完整模型得分高归因于大震数据。
D0本身已含1970年后的大震；第四特征检验的是D2大震历史空间特征的整体增量，不能再分解为
1950起更早历史、Ms5门槛或特定来源各自的贡献。

ridge使用每起报条件多项位置似然（所有Ms4+训练事件等权）加`0.5×lambda×||beta||²`，
lambda仅0.1/1/10。按“I1训练→I2验证、I1+I2训练→I3验证”滚动选择；每次训练仅用
`issue+h≤验证块起点−30天`且标签当时已可见的期。均值/标准差只由该次合法训练特征计算，
起报等权、格按实际面积权重；零方差停用，不剪裁、不用未来块估计尺度。两个非空验证块等权，
平分选较大lambda；不足两个非空验证块则固定lambda=10。最后只用外折前合法I1/I2/I3重拟合一次，
参数外折内固定，但每次起报都正常更新已经发生的历史地震。

没有训练目标或数值拟合不合格时记下原因，beta=0回到同一K75，不删评价样本、不另开优化器搜索。
用有限log质量计算密度和似然，避免25 km核远处浮点下溢被误判为模型不合法；不添加新概率地板。
不修改冻结D1实现，只复用其条件空间目标的数学形式。

## 6. 怎样判断效果，哪些不是本轮结论

保留C0既有均匀、区域常数、长期KDE、KDE75和长期＋近期参考预测，不重算C0。C2B四折预测保存后，
复用相同目标行、同一首锚点30天/75 km震序定义（非链式扩展）以及全部事件/首锚点/震序平衡/
后续事件视角，统一评分。C0和C2B比较只在同一时限、起报、目标和全国域内进行。

主锚点仍为30天、Ms5–6、60万km²、严格落区的147个首锚点震序召回；同时完整报告7/30/90/180/365天、
两震级档和30/45/60/75/96万km²曲线。各时限目标样本不同，不能比较原始命中数就说某时限更好。
以相对质量除格面积排序，沿用完整格前缀，不跳格、不过预算。不同排序的实际面积可能相差不足
一格625km²，报告逐期面积范围和配对差，不声称实际面积完全相等。仅多1例也保留，但检查是否
全靠最后边界格或单一折，不为此另造复杂几何系统。

每个模型给出训练/内层选择信息、四个较晚开发折的命中与漏报、信息增益、配对新增/丢失以及
不确定性。沿用2000次、种子147的非重叠时间曝光重采样，保留期内震序整体；不把格子、时限或
面积档当额外独立样本。95%区间只表达不确定性，不再加“必须显著才有科学价值”的通用否决门。
本次主要是位置研究，不能声称已经改进发生次数、震级概率或联合校准。

静态图首先展示实际召回与面积曲线，再给同一起报的预测地图和成功/失败案例；离线交互页回放已
保存预测，不能伪装成当前真实未来预测。完整格前缀还不是“最多10个连通区”的最终产品，后续
区域化需再验效果。浏览器本地file自动访问已被策略拒绝，不绕过，不阻塞科学计算。

## 7. 执行、停止点与交接

1. 本协议与仅统计训练数量的账本验收、提交、推送；只许可下一项有限实现。
2. 实现位置专用训练/预测/评分路径，先合成验证时间边界、panel成员、归一化、内层隔离和配对；
   不调用包含负二项/震级的旧完整跑法。必要检查后验收、提交、推送。
3. 默认2、最多3个折工作线程，数值库单线程，BelowNormal，至少保留2个物理核心；先查重复实例。
   每折保存内层选择和预测检查点，全部四折完成后评分。
4. 结果形成立即按目标做科学复审：保留真实小增量，列负结果，关闭没有增量的分支；有限问题
   完成后结束S1、进入S2断层/危险性/应变，不再重新搜索95%、Mc格尺度或更多目录候选。
5. 聚合报告和静态图公开同步；逐事件文件、NPZ和含逐事件内容的离线页只保留本机。完整阶段
   必要测试、科学验收、提交推送后再进入下一阶段。每次心跳更新可安全恢复的位置。
