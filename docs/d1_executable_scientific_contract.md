## 1. 这次究竟要回答什么

在三个真实历史时间外推折、相同报警面积和严格因果时间边界下，比较长期多发区、最近 30 天
地震、报告覆盖、单期异常和动态异常，判断它们能否提高未来独立 M5–6 震群的空间召回。

一级问题固定为：未来 30 天、600,000 平方公里报警面积下，相比 `B0`，增量模型多命中了多少个
独立 M5–6 震群。达到 `B0` 相同召回所需的最小预登记面积为并列重要结果。D1 用于发现和筛选，
不是锁定测试，也不冒充真正前瞻证明。

## 2. 用什么数据，哪些数据不用

### 2.1 本次使用

- `earthquake_event`：40,898 条去重地震。每个起报时刻只读取当时已发生且已可见的记录；M4+
  用于背景、近期活动和 Poisson 训练，M5–6 只用于外层评价。
- `anomaly_report_period`：205 个实际异常报告期，只读取 `report_id` 和 `available_at` 来形成实际
  起报日历。
- Stage 3 异常特征：205 个因果快照、15,697 个固定查询格、3,217,885 行。只使用机器合同列明的
  200 km 特征；空间置乱还使用同一特征包的166,189行因果状态历史。不得用 Stage 4 草稿网格
  替换已验收的 Stage 3 网格。
- 冻结的中国大陆研究区和 25 km 精确裁剪网格。
- 39 个目标无关静态分区：只用于区内空间置乱和区域诊断，不得成为模型特征。

所有输入以机器合同中的文件 SHA-256 为身份；本机绝对路径不是科学身份。

- 异常表中的人工预测地点、震级、时间和人工结论；
- 断层属性与长期危险性快照；
- 锁定测试；
- 过去任何模型效果、命中、召回、信息增益或效果地图；
- 树模型、神经网络和事后增加的交互项。

完整断层危险性只能从可证明可用的 2026-07-13 以后做真正前瞻慢窗口，不能倒灌本次历史回放。

## 3. 时间边界与防止偷看未来

- 时区统一为 `Asia/Shanghai`；起报时刻来自实际报告的 `available_at`。
- 任一预测输入只能使用 `origin_time <= T` 且 `available_at <= T` 的来源。
- 目标窗固定为 `(T,T+h]`，起报时刻本身不属于未来目标；历史结果只从冻结的地震目录读取，
  并要求其 `available_at` 不晚于目录冻结时刻 `2026-07-09T04:25:56Z`，不能错误地要求未来目标在
  起报日已经可见。
- 三个评估起报区间为：
  - F1：`[2023-07-01, 2024-04-01)`；
  - F2：`[2024-07-01, 2025-04-01)`；
  - F3：`[2025-07-01, 2026-04-01)`。
- 每折拟合 issue 必须满足 `T <= 评估起点-90天`；其30天拟合目标因此最晚在评估前60天成熟。
- 30 天和 90 天曝光分别从完整时间轴最早实际 issue 开始，随后机械选择最早满足
  `T >= 上一期 T + horizon` 的 issue；不能在折边界重新开始而重复目标。
- 同一目标只归属于生成它的 issue 曝光和对应折；不得随机拆分网格行。

M5–6 规则化独立震群在全部 30/90 天评估目标的并集上一次构造：事件间绝对时间差不超过
2,592,000 秒且 WGS84 椭球测地距离不超过 75,000 米时连边，取无向连通分量。共享震群宇宙是
为了让同一物理序列在不同 horizon 中保持一致，不让模型成绩反过来定义震群。每个 horizon 内以
最早合格事件为代表，同刻并列按
`event_id`；严格命中只看代表事件位置，一个震群在同一 horizon 最多计一次。

目标震中先投影到冻结的 WGS84/Albers 等面积坐标，再按25 km、原点 `(0,0)` 的 Stage 3 网格归格。
内部格线采用高侧半开优先；若点精确落在研究区外边界格线上而高侧格无正面积，则依固定高侧到
低侧顺序选择实际覆盖该点的相邻裁剪格。事件空间对数密度统一为
`log(格概率质量/格精确裁剪面积km²)`。

## 5. 九个预定义科学组

所有源特征先在对应外层训练期内处理：有限值保持原值，非负量用 `log1p`，有符号轨迹用
`asinh`；按训练期 0.5%/99.5% 分位裁剪，以训练期中位数填补，再以中位数和稳健尺度标准化。
组分数是方向对齐后源特征 Z 值的等权平均，并再次只用训练期规则标准化。尺度恒为零的组系数固定
为零。缺失指示作为控制项，不计入九个科学组：`MC1` 是 C1 两源任一缺失的0/1值，`MS45` 是
S4/S5任一源缺失的共享0/1值，`MD1/MD2` 是各自三源缺失数除以3；它们不再标准化、惩罚因子为1，
并随任一父组自动进入模型。质量码、valid 标志和 sample count 不得作为预测量。

| 组 | 角色 | 内容 |
| --- | --- | --- |
| `C1` | 覆盖控制 | 当前/过去一年台站报告完整度、测项报告完整度 |
| `C2` | 覆盖控制 | 当前报告台站广度、测项广度 |
| `S1` | 单期异常 | 可靠性加权的当前异常负荷 |
| `S2` | 单期异常 | 首次出现异常负荷 |
| `S3` | 单期异常 | 未继续异常负荷；不预设物理正负方向，由模型系数判断 |
| `S4` | 单期异常 | 学科多样性 |
| `S5` | 单期异常 | 空间集中度 |
| `D1` | 动态异常 | 当前异常负荷的 13 周斜率、4 对 13 周加速度和峰后回落 |
| `D2` | 动态异常 | 首次出现异常的 13 周斜率、4 对 13 周加速度和峰后回落 |

`A_dynamic` 明确包含 `A_snapshot`，即动态模型使用 `S1–S5 + D1–D2`，不是只使用两条轨迹。

以下候选在不看目标的情况下剔除：多学科实体加权比例全为零；扩散半径与集中度确定性重复；
报告存在标志恒为一；13 周 surge 缺失过高，只留作敏感性；平均年龄物理方向含糊；4 周斜率与
13 周斜率及加速度代数冗余。全局报告连续性在同一期各空间格相同，只作诊断，不进入空间模型。

## 6. 六个固定模型

1. `B0`：每期用当时可见、研究区内 M4+ 地震因果重建 75 km 等权各向同性 Gaussian KDE；
2. `B0_R30`：`p_R=(1-α)p_B0+αp_recent`，近期窗精确为 `(T-30d,T]`；
3. `B0_C`：以 `B0` 为偏置，加 `C1+C2`；
4. `B0_C_A_snapshot`：以 `B0` 为偏置，加 `C1+C2+S1–S5`；
5. `B0_C_A_dynamic`：以 `B0` 为偏置，加 `C1+C2+S1–S5+D1+D2`；
6. `B0_R30_C_A_dynamic`：以 `B0_R30` 为偏置，加全部覆盖、单期和动态组。

`B0` 从 1970-01-01 起使用合格 M4+，在冻结完整研究区归一，并在 25 km 业务格上输出概率质量。
局部 Mc 过高只标记对应局部单元，不能提高其他区域门槛。R30 没有合格事件时精确退化为 `B0`。

## 7. 条件空间训练与训练内选参

特征模型用拟合期每个 issue 之后 30 天的唯一 M4+ 网格计数训练，而不是用稀少 M5–6 直接拟合。
由于最终问题只问“有限面积该画在哪里”，训练把每期地震总数剖面掉，只学习当期内部的空间分布：

`log(p[t,c]) = log(p_base[t,c]) + X[t,c] * beta - logsumexp_c(log(p_base[t,c]) + X[t,c] * beta)`

这等价于把普通空间 Poisson 中每个 issue 的总发生率剖面掉。目标函数是全部拟合期 M4+ 事件
等权的平均负对数空间质量，加 `lambda/2 * ||beta||^2`；没有未来 M4+ 的 issue 对空间系数不提供
似然。`p_base` 已是包含精确裁剪面积的格概率质量，不能再次乘格面积；预测时在全部合格格上
重新归一。禁止用任意 epsilon 或
裁剪掩盖零密度、非有限值或不收敛；这种情况记 `invalid_run`，只允许最小实现修复后按同一合同重跑。

- `α` 候选：`{0, 0.25, 0.5, 0.75}`；
- ridge 候选：`{0.1, 1, 10}`；
- 每折内部验证取拟合 issue 尾部 `max(3, ceil(n/3))` 个，每个验证 issue 只用它之前的拟合 issue；
- 内部评分为 M4+ 目标上逐事件等权合并的预测格对数密度；
- `α` 并列取更小值，ridge 并列取更强惩罚，容差均为 `1e-12 nats/事件`；
- 内部 M4+ 少于 10 个时固定退回 `α=0`、ridge=`10`，并标记调参证据不足；
- 外层 M5–6 目标绝不能选择特征、`α`、ridge 或任何实现选项。

每个外层折只用内部 M4+ 在 `B0` 与 `B0_R30` 的背景比较中选择一次 `α`，同折所有含 R30 的
模型共用该值；不能让完整异常模型另选一个更有利的近期权重。

优化器固定为 float64、零初值的 SciPy L-BFGS-B，最多 2,000 次迭代，`ftol=1e-10`、
`gtol=1e-6`。

## 8. 公平评价、置乱和小提升等级

报警面积档固定为 300,000、450,000、600,000、750,000 和 960,000 平方公里。每格按
“格概率质量/精确裁剪面积”降序，随后按 `row,column,cell_id` 升序处理并列；只取完整格前缀，
累计面积不得超过预算；遇到排序中的第一个超预算格即停止，不跳过它去挑后面的较小边界格，
并报告实际选中面积。

- 一级指标：三个折合并的 30 天、600,000 km²独立震群召回；
- 并列效率指标：达到 `B0` 召回所需的最小预登记面积；
- 次级指标：90 天召回、召回—面积/Molchan、震群代表连续空间 IG、等权折宏平均、区域方向和
  去最大震群方向；
- 支持域外目标保留在全研究区分母并计为未命中；无目标记证据不足；任一模型密度为零或非有限值
  记无效运行，不加 epsilon；
- 六模型和全部折必须完整报告，不能只展示赢家。

不确定性使用根种子147、PCG64的2,000次配对震群 Bootstrap。30天和90天分别从该 horizon
按ID排序的有效全局震群中抽取同样多的震群并有放回抽样；同一 horizon 内模型和面积共用抽样，
不同 horizon 不强行假装是同一组样本。报告候选减 `B0` 的原始多命中震群数、百分点、
2.5%/97.5%百分位区间以及
`P(增益>0)`。Bootstrap 条件于已拟合模型和已观测震群，不在每个复本中重训。

异常归因另做各200次时间和空间置乱：

- 预登记的异常统计只有三项：snapshot 相对 coverage、dynamic 相对 coverage、dynamic 相对
  snapshot 的30天固定面积震群召回差；
- 时间置乱在全部205个真实报告期的完整周度轴上进行，保留未评分的中间期和最多52周预热历史；
  固定接收方 issue 日历和覆盖，在每折拟合截止前后分别置换；`S1–S5` 原始值、缺失状态和原因码
  联合移动，
  listed/first-seen 两条基础序列联合移动，预计算动态列不得直接搬运，`D1/D2` 必须从伪历史重建；
- 空间置乱以同一期、同一目标无关分区内的异常实体坐标对为单位，保留非坐标内容、坐标多重集和
  覆盖，再在 200 km 上重建单期与动态特征；
- 每个复本重新做预处理、内部选择 `alpha/ridge` 并重新拟合；背景、目标和 issue 日历固定；
- p 值为 `(1 + null>=observed 的次数)/(200+1)`；真实异常超过至少80%置乱结果才可称为有希望的
  异常机制；科学置乱复本失败时保守计入 `null>=observed`，失败超过5%则结论为证据不足；置乱是
  归因检查，不是整体组合的自动生死门。

开发证据等级固定为：

- **稳定强线索**：合并后至少多命中2个震群，`P(增益>0)>=0.90`，无一折多漏超过1群；
- **有希望线索**：至少多命中1群、`P(增益>0)>=0.80`、至少2/3折不变差；或相同命中数下少用
  至少一个面积档；
- **弱线索**：方向为正但水位不足或折间混合，且无明显伤害；只允许一次预登记100/300 km尺度
  或惩罚敏感性，随后进入前瞻或停止；
- **无增量或有害**：不多命中、也不省面积，或异常与置乱无区别，或完全由单一区域/震群驱动；
  删除对应组件并保留更简单模型。

5个百分点是强证据，不是继续研究的唯一门。可信负结果也是实质性科学证据，不能误写成工程失败。

## 10. 中断恢复和资源边界

- 默认4个 worker、每个 worker 的 BLAS/OpenMP线程为1，始终至少保留2个物理核心；
- GPU 只有在 float64 数学结果与 CPU 等价时可加速，不能改变模型和排序；
- 检查点单位为一个“外层折×模型”或25个置乱复本；
- 状态至少记录合同、输入、Git提交、折、模型、置乱类型、最后复本、已完成单元和状态；
- 只有合同和输入哈希完全一致才能续跑；不以旧 PID 判断现场状态；
- 有效成绩形成前的实现错误记 `invalid_run`，最小修复后按同一合同重跑，禁止从多次重试中挑最好；
- 锁定测试仍只允许一次，本阶段不运行。

## 12. D1-0 验收与科学价值

恢复 RFC3161、证书链、硬件收据、逐工件注册等已退休工程门。
