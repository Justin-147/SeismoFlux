## 1. 研究问题与证据边界

通俗说：断层图告诉我们“哪里有断层”，速率资料还告诉我们“这些断层活动有多快”。这轮检验后者
是否能帮助现有目录模型少漏地震区域，并分清收益来自新增覆盖、断层几何还是速率大小。
不是用滑动速率直接推断某一天将发震，也不把相对评分称作绝对概率。

使用2026年收集的静态资料回看2000—2019年地震空间分布。观测时段、反演方法和历史版本不全，
保留`historical_model_eligible=false`，不能宣称这些属性在历史起报时已经可用；静态图及其速率
也可能受后来调查影响。本轮属于**当前静态资料的描述性开发比较**，不是新的真正前瞻证据。
不因这个局限停止探索，也不据此打开2020—2022留出、2023+审计或锁定测试。

主要问地点是否改善；保留7/30/90/180/365天、Ms[5,6)与Ms≥6全部原定条件，重点解释90/180/365天
和较大地震，但不在看成绩后改主指标，不据此声称时间或震级预测已经改善。

## 2. 经典方法先行与此次采用的范围

- [Youngs与Coppersmith（1985）原文](https://www.resolutionmineeis.us/sites/default/files/references/youngs-coppersmith-1985.pdf)：
  已阅读摘要及940—943页。长期滑速可约束地震发生率，但要说明地震滑动、断层面积、剪切模量和
  震级频度等假设。本文不具有完整输入，因此不计算地震矩率或绝对发震率。
- [程佳等（2020），《地球物理学报》原文](https://html.rhhz.net/dqwlxb/2020-3-1170.htm)：
  已阅读方法部分，区分断层滑速、GPS应变和背景地震的贡献。其长期危险性/大震模型不是本项目
  的7—365天模型；本轮不照搬其震级换算、震源分区或危险性平台。
- [Rhoades与Stirling（2012）作者机构摘要](https://central.scec.org/publication/1521)：
  已阅读作者摘要，支持目录信息与断层滑速空间信息作有限组合这一思路。未取得全文，不能声称
  复现其具体计算式；本轮高斯线积分是明确登记的简化变体。
- [Bayona等（2021）原文](https://academic.oup.com/gji/article/224/3/1945/5996192)：
  已阅读GEAR/WHEEL方法与比较结果。构造/测地信息和目录信息可能互补，单一物理层也可能过度
  集中。其全球Mw目标与中国Ms任务不同，不能借用论文成绩替代本轮实测。

采用上述“物理空间层单独比较，再与目录组合”的有限路线。核函数采用常规二维高斯，沿给定
断层线积分；这是本轮可复核的建模假设，不冒称某篇未读全文的逐式复现。不建设PSHA系统。

|NATIVE_GD|NATIVE_GD|测地总速率|S2B_NATIVE_GD_ONLY|S2B_NATIVE_GD_CATALOG_MIX|

对于原简化线L_j、网格内部代表点x_i、实际裁切格面积A_i，以公里计算：

```text
K_s(r) = exp(-r²/(2s²)) / (2πs²)
q_s(x_i) = Σ[j∈S] v_j ∫[u∈L_j] K_s(||x_i-u||) dℓ
F_s(i) = A_i q_s(x_i) / Σ[k] A_k q_s(x_k)
P(i) = (1-α) C(i) + α F_s(i)
```

所有线沿原顶点投影到既有China Albers等面积坐标，沿每条投影直线边积分；位置查询沿用原
裁切格的point-on-surface，不新造网格或候选位置。WGS84是既有坐标解释而非独立测绘确认。
**不能先把每条断层归一成单位总量**，否则线段人为拆分会改变相对贡献；总贡献随长度×速率变化。
保留原始线，不自动融并、修图或改边界。长度是地图线长度，不是某次地震的破裂长度。
等权线层用于控制同一套几何/积分方法，不能把S2-A最近线反幂方法与本轮之差全归为速率贡献。

F与P均为归一化相对空间质量，排序用质量/实际面积。单位转换只差全局常数时归一后不变；
这不等于具有物理量纲的地震矩率，也不是绝对发震概率。计算使用float64对数空间，保留高斯
远端尾部，不加人为概率底噪、截断半径或新的背景权重。
