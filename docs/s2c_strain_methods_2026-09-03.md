# S2-C：独立应变信息的有限增量比较

不重跑S1/S2-A/S2-B，不读留出或锁定测试。本轮仅GSRM独立应变，危险性综合评分不混入。

## 1. 问什么，用什么数据

问题：同样大小的报警区域内，独立应变信息能否补充目录预测？要分清变形区的位置与变形强弱。
新增数据为作者公开的GSRM v2.1变形单元均值，145,086行、单位10^-9/年，文件头2014-03-01。
它是由大地测量反演的长期水平应变产品，不是逐日异常、原始台站时序或断层滑动速率。
源文件及获取清单位于`D:\AIPred\SeismoFlux\data\external\gsrm_v2_1_20260903`；不重复下载。
两份Ms目录、原25km全国研究格、所有目标与空期保持不变，不因应变低/零或缺资料删目标。

## 2. 经典依据与本项目取舍

[GSRM官方方法](https://gsrm2.unavco.org/methodology/methodology.html)明确：原变形单元经向0.25°、
纬向0.2°，其余地区按刚性板块/地块建模；这是模型分区，不是GPS观测覆盖率。本文采用该原单元
范围及官方标量`S=sqrt(exx²+eyy²+2exy²)`，不新增应变估计器或平滑尺度。

[Bird与Kreemer（2015）](https://geodesy.unr.edu/publications/bird-kreemer_BSSA_2015.pdf)给出了
应变转长期地震活动的SHIFT假设，需耦合发震厚度、剪切模量、构造类别及震级频度等。本轮没有
这些完整物理约束，故不冒称SHIFT复现、地震矩率或绝对概率，只检验相对应变强度的地点信息。
原文也指出刚性区零应变不代表零地震活动；因此保留目录混合作为可用预测候选，纯层零值的失败
如实报告，不把软件要求“有限数值”当作加底噪的科学理由。

国内[程佳等（2020）](https://html.rhhz.net/dqwlxb/2020-3-1170.htm)把滑速、GPS应变和背景地震
分别纳入长期危险性，支持分量研究思路；本文不复制其Mw换算、分区或地震动目标。
本项目的面积预算、混合候选和统计评价是预登记的研究选择，不冒称文献唯一规定。

## 3. 空间处理与四个模型

每个原记录中心构成经度±0.125°、纬度±0.1°的源矩形。经纬边界按最大0.05°分段后投影到
现有中国Albers等面积坐标，和原研究格的裁切多边形相交；按相交面积a_ij汇总，单位km²。
这是假定原单元内标量常值的面积守恒重映射，不把中心点当独立地震样本，也不按震中改边界。

令S_j为上述官方第二不变量；全国归一两层：

`F_i = sum_j(a_ij*S_j) / sum_kj(a_kj*S_j)`；
`U_i = sum_j(a_ij) / sum_kj(a_kj)`。

U是同一变形单元支撑的等密度对照，不是全中国均匀；F相对U检验强弱而不混淆支撑位置。
原文件完整枚举模型变形单元，其余研究域是该产品的模型刚性区，质量为0，不等于无地震风险。
数值非有限、重复单元或来源身份不符属于真实输入错误，不用填零掩盖；不对张量作截尾/补值。
不使用误差列倒数加权；其0误差不能假定无限精确。方向、e1/e2仅一次一致性诊断，不作新特征。

四个新模型为`S2C_UNIT_ONLY`、`S2C_UNIT_CATALOG_MIX`、`S2C_STRAIN_ONLY`、
`S2C_STRAIN_CATALOG_MIX`。纯层没有参数；混合为`(1-alpha)*C+alpha*U/F`，
alpha仅0、0.25、0.5、0.75、1；C为已保存的多尺度目录背景，不重算目录核，不新增尺度或变换。

## 5. 真零与统计解释

保留零质量，log质量允许-inf，拒绝NaN、+inf及全国全零。混合alpha=0/1精确保留端点。
内层只对count>0计分：正计数落零区时该块分数为-inf，不删该事件或整块；空块才为NA。
有限得分优先；所有候选都-inf时按较小alpha平局规则选并明记原因，不做inf差值比较。
纯层无需用-inf得分再选参数。外层排序中零密度并列按原行/列/ID规则处理，面积仍按完整格前缀。

外层对数密度可为-inf，原表保留；JSON用null及明确`negative_infinity_from_zero_mass`标记，不与
无事件NA混淆。两个-inf的信息增益未定义，不写成0。独立锚点召回、得失、分母和实际面积照常报告。
真零只需新的S2-C局部适配，不能修改旧模型源码、重跑旧成果或为此开发通用概率平台。

保持原2,000次曝光/整震序配对重采样及完整正负结果，区间不作一票否决。六组预定配对见配置；
四折及2015—2019各有800条曲线、600组配对条件，它们不是独立实验次数。
小而任务专用的收益留给S5；没有增量就关闭本分支，不追加尺度、权重、场版本或新的后验变换。
