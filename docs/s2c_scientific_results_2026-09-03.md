# S2-C独立应变资料：训练与较晚评价

更新时间：2026-09-03 03:14（北京时间）。状态：`FINITE_SCIENTIFIC_COMPARISON_COMPLETE`。
四折预测、评分和真实图件已完成。结论：主30天任务没有新增召回；保留少数长时限、小面积
条件的应变线索供S5，结束本轮应变扩搜，下一项实质科学工作为S3动态异常。

## 1. 通俗说明

在原有地震目录模型上，加入一份由大地测量得到的长期地壳变形资料，观察同样面积的报警区
能否多包含一些后来发生的地震。分别比较“哪里在变形”和“变形有多强”，避免把位置本身的
贡献错算成强度的贡献。变形较小或模型认为刚性的地方仍然可能有地震，所以不删这些地区的样本。

## 2. 用了什么数据和方法

- 目录：`china3new.eqt`与`1900年以来5级以上地震目录_simple.xlsx`，按用户确认Ms原数值使用。
  目录多尺度背景沿用S1已保存结果，其几十年可用历史不因应变产品的年代而截短。
- 新资料：GSRM v2.1单元平均应变率，源文件145,086行14列，单位10^-9/年，标注2014-03-01。
  它是长期平均空间场，不是每天观测的异常或原始GPS站时间序列。
- 特征：官方标量`sqrt(exx²+eyy²+2exy²)`及相同变形单元支撑的等密度对照。
  按原单元与既有25km研究格相交面积累计，不按震中改变格网或选候选。
- 模型：UNIT单用、UNIT与目录混合、STRAIN单用、STRAIN与目录混合。混合权重仅0、0.25、
  0.5、0.75、1，使用每外折之前成熟的I2/I3历史选择；不按后来成绩调权。
- 本轮未混入：危险性四项综合分数、2026离逝率、断层滑速、人工预测结果和动态异常。
  后几类分别已有实验或等待后续对应阶段，不能把它们的贡献归给应变。

## 3. 实际处理范围

中国研究域包围盒相交候选24,677个原单元，候选中无重复；不等于所有候选都与裁切国土实际相交。
全球源文件50个重复中心都在经±0.125°，不参与中国积分，原始记录没有清洗、平均或改写。
域外检查范围纠偏与首无效运行记录见`docs/s2c_source_scope_fix_2026-09-03.md`。

原研究格共15,697格，UNIT有4,041格质量为0，STRAIN有4,156格为0；变形单元与研究域相交
面积为6,952,091.93km²。这是GSRM的模型变形支撑，**不是GPS观测完整率**。
原全部研究格、目标和空期仍保留，没有95%/80%全国面积门，也没有Mc掩膜。

## 4. 训练结果：有些时限选应变，主30天任务没有选

共有20个“外折×时限”选择单元，各自I2/I3合计103—1,132个Ms≥4事件、8—87个起报期；
这些相互重叠的数目不能相加冒充独立地震数。

|模型|选择目录原样（alpha=0）|选择加入25%静态层|其他权重|
|---|---:|---:|---:|
|UNIT＋目录|15/20|5/20|0|
|STRAIN＋目录|8/20|12/20|0|

UNIT的非零选择出现在2000—2004的7/180/365天、2005—2009的7天、2010—2014的365天。
STRAIN的非零选择出现在前三折的7/90/180/365天。**四折30天均选alpha=0；2015—2019
全部时限均选alpha=0。** 这是使用更早资料得到的选择，不是看过本次较晚成绩后退回目录。

被选混合的内层得分均有限。平均“非空块平均对数密度”相对alpha=0改善：UNIT为0.00243
（单元范围0—0.03687），STRAIN为0.02878（0—0.07773）。因为候选本来包含目录，选后的训练
得分不低于目录并不是外推有效的证明。

两个纯层均没有拟合参数，各自40/40内层块出现负无穷对数分数：每个块至少一场地震发生在
该纯层质量为0的格。它不是无标签或数值崩溃，未通过删事件或填底噪改善分数。

小面积应变作为S5的次级任务专用候选，不据此增加新权重、尺度、来源或变换。

## 7. 零应变、时间属性与证据边界

- 两纯层各自全四折100条模型曲线中90条对数密度为负无穷、10条有限；2015—2019为60条
  负无穷、40条有限。原因是部分地震落在纯层零质量格，不是文件缺失、无标签或计算崩溃。
  JSON以null配合明确的负无穷状态保存；混合得分有限，没有删事件或填底噪。
- GSRM是长期平均空间资料，不是可以据以判断某一天临震的实时异常。产品2014标注也不证明
  当前文件与当年字节完全相同；早期折属于回看，2015—2019亦是已使用的开发期，非新独立测试。
- 本轮主要评价地点信息，不能自动推出时间、震级概率或未来预测提升。格网报警前缀仍不是
  最终最多10个连通区的区域产品；相对评分不称绝对发震概率。
- 危险性综合分数缺历史版本，2026离逝率/2025最后震不能回填；本轮未训练该层，也未训练205期
  动态异常。不能把S2有限比较结束描述成所有用户数据已用完。
- 95%全国支持面积门已经取消，两用户目录按Ms原数值使用。本轮没有全国80%新门、Mc掩膜或
  震级类型空缺删样本；不需要因这两个问题重跑S1、S2-A/B/C。

## 8. 科学价值复审与下一步

1. 是否推动最终目标：主条件没有新增召回；厘清“支撑位置”和“应变强弱”的贡献，留下少量
   长时限、小面积线索，是有限科学证据，不是可靠预测能力的确认。
2. 是否偏离方案：没有；按冻结四模型和全部正负条件比较，未据外层成绩追加搜索。
3. 是否陷入无益工程：没有继续处理与中国积分无关的全球重复源；图件只用于读懂结果，
   自动浏览权限受限不构成再造展示平台或阻塞科学阶段的理由。
4. 是否调整或停止：结束本轮S2-C扩搜，不替换主模型；STRAIN保留为S5次级候选，UNIT仅作
   归因对照。阶段必要验收、提交和推送后进入S3，检验205期动态异常是否补充短时变化信息。

此前S2-B主条件最好为60/147（40.8%），来自515段等权几何与目录的混合，不能归因滑速或
本轮应变；仍漏87个锚点。整个项目尚未完成，多数据学习、组合消融、独立验证仍需推进。
