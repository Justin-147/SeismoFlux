>
> 机器状态：`not_materialized_scientific_fallback`

## 1. 外行版：为什么最后没有选5折、4折或3折

原计划是把39个空间小块合成5折、4折或3折，选择“检验能力足够”的最大折数。但S0只写了候选
折数和几何聚类方法，没有写清楚以下关键问题：

1. 要检验的具体差异是什么；
2. 多大的预测提升才值得检出；
3. 允许多大的误判概率、要求多高的检出概率；
4. 模拟多少年的地震；
5. 用什么历史背景率和目录完整度假设；
6. 是要求每一折都足够，还是全国合并后足够。

没有这些条件，“功效足够”没有唯一答案。现在临时补一个门槛，再用它选出某个折数，仍然是人为制定
规则，并不比凭直觉选5折更科学。因此本阶段没有算5、4、3哪一个“最好”，而是在看到任何模型成绩
以前停止这条欠定路线。

今后模型参数只根据更早年份预测更晚年份的嵌套时间前推来选择。已经冻结的39个原子块仍然有用，
但只在模型完全冻结后逐块留出，检验参数能否迁移到“该块评价目标未参与拟合”的地区；起报前已因果
可见的块内历史仍可作为预测输入。39份结果必须拼成一张全国OOF面，每档全国报警面积只用一次。

## 3. 国内外经典方法给出的约束

1. 中国CSEP2.0及国际CSEP的主问题，是在事先固定的区域、格网、震级、时间窗和指标上做时间向前
   检验。它们不规定“39块必须合成5折”。因此模型选择退回时间前推，不会损害本项目的主要估计目标。
2. Roberts等空间阻塞交叉验证研究指出，空间折要与实际迁移距离和预测问题匹配，折数并不存在通用
   最优值。空间留区适合作为迁移压力测试，但不能冒充固定区域内的未来预测主证据。
3. Khawaja等关于空间地震预测检验功效的研究表明，功效取决于事件数以及两个被比较预测之间的差异。
   只有`k`和事件总数，不能推出一个普适的“功效足够”结论。

依据：

- Zhang et al. (2024), CSEP2.0 China：<https://doi.org/10.1111/1755-6724.15250>
- Roberts et al. (2017), structured cross-validation：<https://doi.org/10.1111/ecog.02881>
- Khawaja et al. (2023), power of spatial earthquake forecast tests：<https://doi.org/10.1093/gji/ggad030>

这些依据支持“停止任意选折”，但不支持临时发明一组alpha、power或最小信息增益数字。

## 4. 冻结决定

| 项目 | 冻结值 |
| --- | --- |
| 较少空间折状态 | `not_materialized_scientific_fallback` |
| 选定折数 | `null` |
| 39→k映射 | 不生成 |
| 候选5/4/3是否计算 | 否 |
| 模型/超参数选择 | 仅嵌套时间前推 |
| M6+是否参与选折 | 否 |
| 39块是否保留 | 是，模型冻结后的次级LOBO迁移压力测试 |
| 39块是否用于调参 | 否 |
| LOBO面积口径 | 39份OOF拼回全国面后，每档全国面积预算只施加一次 |
| 单块效果主张 | 禁止；单块稀疏且大小差异很大 |

该决定不是说空间迁移不重要，而是把两个问题分开：

- **主要问题**：过去能否预测未来——用嵌套时间前推选择模型；
- **次要问题**：学到的规律能否搬到其他地区——模型冻结后用39块LOBO检查。

## 7. 科学意义、限制和下一步

本次没有提升命中率，也没有产生新的训练或外推成绩。它避免了一个会使结果依赖临时人为门槛的设计
分支，属于对后续可信比较的必要纠偏。

代价是S1不能再用较少空间折选择超参数，只能依靠嵌套时间前推；这与全国未来预测的主要问题一致。
39块LOBO仍会带来39次拟合成本，但只在模型和参数已经冻结后执行，不允许利用其结果回头调参。

下一项真正科学工作是：按已经冻结的时间外推折比较仅目录基线，先回答长期率、KDE、近期活动、
Gutenberg–Richter和可评价ETAS/Hawkes在地点、时间和震级任务上是否有稳定增益。待模型冻结后，再用
39块LOBO检查跨区迁移。该决策现在可以在任何模型成绩出现前封存。
