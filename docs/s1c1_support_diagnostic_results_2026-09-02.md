# S1-C1 局地目录完整性支持诊断结果（2026-09-02）

> 本阶段只检查历史目录能否支撑全国局地完整震级（Mc）比较，没有生成预测、没有读取目标答案，
> 也没有计算任何模型成绩。

## 1. 通俗结论

这条检验没有通过预先写死的数据门，因此已经在预测前停止。

我们把中国大陆分成固定的500 km大格；每个格至少需要200个当时已经可见的历史地震，样本不足时
才借用所在1000 km父格。只有能估出Mc且Mc不高于4的面积才算“有证据支持”。冻结规则要求16个
训练节点的全国支持面积都达到95%，实际一个也没有达到：最低51.15%，最高88.55%。

主要缺口不是“很多地区Mc过高”，而是稀疏地区历史事件不足，无法可靠判断Mc。换句话说，现有目录
不能支持这套严格的全国局地Mc消融；这不等于全国目录只有51%–89%完整，也不否定S1-C0中L2/L3
相对简单区域常率的正向开发信号。

## 2. 用了什么数据、怎样处理

- 唯一真实输入是权威地震目录`earthquake_event.parquet`，共40,898条；Mc诊断使用研究区内、
  1970年起且在每个节点截止前已经发生并已经可获得的目录事件。
- 16个协议节点由12个内层训练块起点和4个外折起点组成；由于不同折复用相同历史起点，实际对应
  1985、1990、1995、2000、2005、2010和2015年七个不同日历锚点。
- 每个节点的目录截止固定为锚点前24小时，既限制地震发生时间，也限制数据可获得时间；后来的地震
  不会回填到较早节点。
- 空间规则为固定零原点500 km格，样本不足时回退到固定1000 km父格；至少200个事件，MAXC峰值
  加0.2，并列峰取较高震级箱。原始Mc大于4只影响该500 km训练格，不影响其他地区。
- 全国研究区和25 km预测格没有缩小；总面积固定为9,415,305.754 km²。
- 异常周报、断层、危险性、应变、人工预测、未来目录、holdout、audit和locked test均未使用。

## 4. 对预测目标意味着什么

- **得到的证据：** 严格全国局地Mc消融的数据基础不足，不能公平回答“控制局地完整度后，L2/L3
  的同面积召回提升是否仍保留”。
- **没有得到的证据：** 本阶段没有训练效果、测试效果、召回率或模型排名，不能称为模型失败。
- **保留的证据：** S1-C0在30天、M5–6、约60万km²下，L2为46/147、L3为54/147、L1为
  32/147的开发期结果仍原样保留，但L2/L3不能仅凭该结果晋升最终冠军。
- **科学决定：** 按冻结协议记为`evidence_insufficient`，停止C1-P2预测和C1-P3评分。不能事后
  降低95%、删除早期折或难预测目标、缩小全国范围、扩大报警面积，也不能继续调500/1000 km尺度。

这项工作属于必要的数据质量诊断，并通过及时停止避免把稀疏区的不确定性伪装成模型提升；它没有
直接提高预测效果。
