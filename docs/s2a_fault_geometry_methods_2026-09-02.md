# S2-A：断层几何对地点预测的有限增量试验

日期：2026-09-02。机器协议：`configs/multitask_s2_a_fault_geometry.yaml`。
本协议在任何S2-A预测或评分前登记；S1开发结果已经看过，故仍属开发研究，不是新的独立确认。

## 1. 这轮要回答什么

在同一批历史地震、同样起报期和报警面积下，比较“只用历史地震热点”和“再加入断层位置”。
同时把断层图变成仅保留39个既定大区分布的粗图，判断帮助来自粗略构造地域，还是更细的断层邻近位置。
已有热点本身是合法有用的预测信息；粗图有效也予以保留，不因缺乏精细机制归因而否定总效果。

S1已经完整关闭，不重跑目录、95%覆盖门或Ms口径。主目录参考为已保存的多尺度模型；年龄模型、
原L3和均匀背景只读保留。当前阶段只研究**地点**，不声称断层图能报出具体发震日期或震级。

## 3. 唯一位置公式与有限候选

使用原25km裁切格网代表点、实际面积A_i和原中国Albers等面积投影。WKB沿用WGS84解释，来源
原始坐标基准未独立确认；距离为投影平面距离，计算统一公里，不冒称精确测地距离。
格网、研究区和39块均不由本轮目标地震生成。

对每一资料源，d_i为格代表点到最近一条可用线的距离：

`q_s(i)=1/[1+(d_i/s)^2]`，`F_s(i)=q_s(i) A_i / Σ_j q_s(j) A_j`。

固定幂2；s只取25、75、150km，表示邻近评分降至一半的距离，不是破裂半径或命中容差。
最近距离不受重复迹线条目影响，不为重复线另开清洗工程。纯F的密度排序对三个s完全相同；
s改变的是密度形状以及混合后的排序，不能把它们算成三个独立的纯断层定位范围。

粗图保留各冻结块总质量，块内按实际面积均分：

`Fcoarse_s(i) = [Σ_{j∈b(i)} F_s(j)] A_i / [Σ_{j∈b(i)} A_j]`。

每源输出纯F、`(1−α)C+αF`、`(1−α)C+αFcoarse`三类，共六个新模型。
α只取0、0.25、0.5、0.75、1；α=0只保留一个原目录候选，因此每种混合13个候选，不全交叉旧14模型。
纯F单独选择s，混合单独选择α和s；比较的是有限程序的优劣，不是假装只改变一个参数的严格消融。
平局容差1e−12：混合先小α，再按s=75、150、25；纯F同此s顺序。全国归一化后混合，保存有限
float64 log质量，不增加人为概率下限。输出为相对空间分配，不是绝对发震概率。

## 4. 怎么训练，怎样避免内层偷看

保留2000—2004、2005—2009、2010—2014、2015—2019四个开发外折，以及每折原I1/I2/I3内层。
每个时限独立选择，两个评价震级档共用位置模型；标签是全国Ms≥4，不按新分数换标签。

1. 预测I2所用目录参数只从I1选择；预测I3只从I1+I2选择。训练目标结束及可见时间均不晚于
   对应验证块起点减30天，每次起报目录仍执行24小时延迟。
2. **保留原C2B的至少两个非空训练块规则**，所以I2仅有I1时明确回退K75；I3两块都非空才选择。
   这是为保持同一目录基底算法，不是新造全国支持比例或停止S2的门槛。所有回退写进训练记录。
3. 用这些更早生成的I2/I3目录预测评价纯F和两种混合。每块先取事件平均log空间密度，再对非空块
   等权平均。S2自身允许一个非空验证块选择；空块记NA而非0，全部无标签时纯F用s75、混合用α0。
4. S2选参标签结束与可见性均截在外折起点减30天。不能用看过I2/I3的最终外折目录参数反填内层。
   最终外折直接复用已保存C2B多尺度预测，只更新组合，不重选或回写旧目录模型。

已保存413份因果核只读复用，缺少则停止并报告，不写回旧运行。记录各块实际起报数、标签数、
目录选择/回退、所有有限候选分数和最终参数。训练分数只说明选择过程，不能代替较晚评价成绩。

## 5. 同样成本评价，如何解释好坏

所有四折共396个起报—时限对的预测保存后再统一评分。原7/30/90/180/365天，Ms[5,6)、Ms≥6，
30/45/60/75/96万km²面积档和0km严格命中不变；70km仅辅助。原固定首锚点30天75km震序不改，
零地震期保留。主参照30天、Ms5–6、60万km²仍147个独立锚点；地质重点另看90/180/365天及大震。

复用已验收参考分数和原目标向量，同一预算内按密度取完整格前缀；不删目标、不缩小评价区。
报告每模型实际面积及微小离散差，不能说实际面积逐位相等。格网排序尚不是最多10个连通区产品。
严格召回、新增/丢失/净命中、每折方向、分时限/震级面积曲线、空间信息和2000次原时间期配对
bootstrap区间一起报告。区间不排除零不自动判无用，不将相关时限/面积当额外独立样本。

11组配对见机器协议。粗化对照不是正式空间置乱，也不是留出地区迁移：

- 精/粗混合均有改善：先保留粗构造地域信息；不能立即归因到精细断层线。
- 精细混合还优于粗化：支持更细表示可能有补充信息，仍需后续迁移/扰动及未来检验。
- 精细/粗化均无收益：关闭本变体，不沿已见外折追加尺度或权重；下一项单独检验属性、危险性或应变。
- 两资料源差异还包括覆盖和制图方式，不能仅归为分辨率。

每个小幅、任务专用正结果和负结果均保存。几何可能改善地点分布，但不能因此声称时间和震级预测
也改善。当前还没有S2训练成绩、较晚评价或静态效果图；必要实现验收后立即运行这个有限对照。
