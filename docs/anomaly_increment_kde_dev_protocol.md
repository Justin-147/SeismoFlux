## 1. 这一步用外行能听懂的话在做什么

先画一张只由历史地震形成的“长期多发区底图”，再问：把截至预测当天已经公开的地球物理异常叠加上去，
能不能在仍然只报警 600,000 平方公里的情况下，覆盖更多随后发生、经目录去重的物理地震事件？

我们不是问模型能否把全国都涂红，也不是问异常附近有没有历史地震。真正的比较是：

> 在相同起报日、相同未来窗口、相同空间格网、相同报警面积和相同地震目标下，
> “长期地震底图 + 当期或动态异常”是否稳定优于“只有长期地震底图”和
> “底图 + 报告覆盖变化”？

如果答案是否定或样本不足，本路线就停下来复审，不用更多代码、更多模型或更大的神经网络寻找阳性结果。

## 2. 为什么现在走这条路线

阶段 2R 已证明 75 km Gaussian KDE 在冻结局部支持域内优于均匀背景，因此它是当前最好且可评价的
非异常背景。KDE 保留了用户强调的科学事实：历史地震多发区本身可能对未来预测有帮助。

Q2 的 ETAS 数值资格结果为 `not_evaluable`。25 个起点都没有离开初始值，所以只能说明当前冻结
ETAS 执行路径不可评价，不能说明 ETAS 或历史地震聚集没有科学价值。本轮把 ETAS 标记为
`not_evaluable_not_scored`，既不填成 0 分，也不继续修补它阻断整个项目。

旧阶段 4 R2 保留为历史目标盲协议和阻断证据。本协议另立 namespace，只继承其中在看目标前已经冻结的
滚动折、特征定义和目标无关空间分层；不继承旧 R2 的 ETAS 执行授权、attempt、seal、ledger 或随机流。

## 4. 四个模型和贡献拆分

| ID | 模型 | 回答的问题 |
| --- | --- | --- |
| `B0` | 75 km KDE | 只靠长期历史多发区能做到什么 |
| `C0` | KDE + 9 个覆盖/缺报控制 | 报告制度变化能解释多少 |
| `B1` | KDE + 覆盖控制 + 当期异常快照 | 当期异常是否有增量 |
| `B2` | KDE + 覆盖控制 + 全历史动态轨迹 | 异常演化是否再提供增量 |

```mermaid
flowchart LR
    B0["B0 长期地震 KDE"] --> C0["C0 加报告覆盖控制"]
    C0 --> B1["B1 加当期异常快照"]
    B1 --> B2["B2 加动态轨迹"]
```

四者共享背景、支持域、训练事件率、补偿积分域、目标、格网、未来窗和报警面积。模型是简单的
ridge 正则化 Poisson 点过程：KDE 作为固定背景，异常只作为乘法强度增量；不含异常截距，不搜索特征、
半径、衰期或正则强度。

冻结参数为：

- KDE 带宽 75 km；
- 异常确认尺度 200 km；
- 未来强度衰减半衰期 90 天；
- ridge `lambda=1.0`；
- 7、30、90 天主窗口；
- 600,000 平方公里主报警面积；
- 三个时间隔离滚动折。

贡献用同折、同目标、同面积的配对差值表示：

- `B2-B0`：完整动态系统相对长期底图的总增量；
- `C0-B0`：仅报告覆盖和缺报制度的贡献；
- `B2-C0`：全部异常在覆盖控制之外的贡献；
- `B1-C0`：单期异常在覆盖控制之外的贡献；
- `B2-B1`：动态轨迹相对单期快照的增量；

这些是预测贡献的消融估计，不称为唯一因果贡献。

异常特征还按五组展示每折标准化系数点估计及三折中位数、最小值、最大值（不伪造 95% 区间或
`p` 值）、标准化效应分布，以及“不重新拟合、只把该组效应置零”的预测敏感性：报告覆盖、
异常活动与延续、学科组成、空间集中/扩散、趋势/加速度/突增/峰后回落。组置零固定报告总体宏 IG
变化、600,000 平方公里召回百分点变化和目标无关格网强度秩 Spearman 相关。该敏感性只解释
已拟合模型，不能称为因果贡献，也不增加采用候选。

## 5. 为什么要做两类“故意打乱”

真实异常若确实有时空信息，应当优于以下假数据：

- **时间置乱**：在训练池和评估池内分别把完整异常快照映射到别的起报日，覆盖率和 KDE 不动，再从
  伪历史重算动态轨迹；
- **空间置乱**：在预冻结、目标无关的空间分层内置换异常实体的坐标对，覆盖率、KDE 和非坐标属性不动，
  再重算 200 km 快照与轨迹。

两类置乱各做 1,000 次，每次都重新拟合异常系数。若真实结果不能同时超过两类置乱，不能把结果称为
物理异常增量。物理事件块 Bootstrap 做 2,000 次，给出 95% 区间。

`B1` 和 `B2` 是两个预登记候选，不能分别计算两个未经校正的 `p` 值后挑较好者。时间和空间置乱
各自形成一个检验族：每个配对复本同时计算 `B1-C0` 与 `B2-C0` 的三折宏信息增益，并取二者最大值
作为该复本的 `maxT`。候选的校正 `p` 值是“复本最大值不小于该候选真实统计量”的比例（含标准
`+1` 修正）；被采用候选的时间与空间 `p_adj` 都必须不高于 0.05。未经校正的 `p` 只作诊断。
`B2-B1` 只决定是否采用动态轨迹，不另造一个 Stage 4A 阳性结论。

若真实 `B2` 单独拟合/评分无效，不能把候选族缩成只剩 `B1`，也无法构造完整四成员同时区间；
因此整体直接归为 `evidence_insufficient`，不采用任何异常候选。不得补种子、替换复本、重算代码
或退化为单候选裸 `p`。

Bootstrap 的抽样单位是三个折、三个窗口并集中经目录去重的物理事件 ID。先按“折 ID ×
该事件是否属于 7/30/90 天窗口的三位成员签名”冻结分层，再在每层内按原层样本量有放回抽样。
同一复本的事件 multiplicity 同时用于所有模型、比较和指标，因此折—窗口事件边际数保持不变；
单元素层只能抽到自身。任何复本失败都把本轮判为证据不足，不删除失败复本，也不用新种子替换。

为防止在 `B1/B2 × B0/C0` 四个对比里挑到偶然好看的区间，信息增益和固定面积召回分别组成一个
四成员家族，并用同一批配对复本构造家族 95% 同时区间。采用透明保守的 Bonferroni 双侧 percentile：
每个成员使用 98.75% 双侧分位区间（下、上分位分别 0.625% 和 99.375%），从而使每个指标家族的
同时覆盖率至少为 95%。通过门只读取同时下界；普通边际 95% 区间可展示，但必须标为仅诊断。

随机根种子 147 以 `root_seed_decimal` 明确进入规范 JSON；其余字段为协议版本、namespace、输入
seal、用途、折/联合角色、分区角色和复本号。JSON 按键排序、紧凑序列化后经 SHA-256 派生
PCG64 子流；候选、比较器、窗口和指标不进入子种子，从而让所有模型在同一复本配对。

## 7. `S4-KDE-DEV` 通过条件

先为每个折、每个主窗口计算一个 `IG(fold,horizon)`。每折宏值是 7/30/90 天三个 IG 的算术平均，
总体主统计量再对三个折等权平均，因此九个“折 × 窗口”单元各占 `1/9`。每个单元至少要有一个
去重物理事件；任一单元为 0 事件时状态是 `evidence_insufficient`，禁止删除该单元做部分宏。
这里“物理事件”表示跨目录去重后的同一地震 ID，不表示地震在统计上相互独立，也不表示余震影响
已经被完全消除。

每个 Bootstrap 复本使用第 5 节冻结的“折 × 三位窗口成员签名”分层方案，对同一个去重物理事件块
联合重采样，保留它跨窗口的成员关系，并按完全相同的“先窗后折”公式重算 IG 和严格召回；曝光补偿项
固定。每个时间/空间置乱复本在重新拟合后也计算完全相同的三折总体宏统计量，不能换成逐窗最好值。

`B1` 和 `B2` 分别作为候选。任一候选要通过共同门，下面第 1–4、6–7 项必须分别相对 `B0`
和 `C0` 满足；第 5 项只对“候选减 `C0`”的异常增量在 `B1/B2` 候选族内做一次 `maxT`
校正，不存在另一个“候选减 `B0`”的 adjusted p：

1. 输入哈希、支持域、格网、目标集合、积分域和面积身份一致，无未来泄漏或目标派生空间设计；
2. 三折 × 三窗口去重后的 M5–6 物理事件并集不少于 20，且九个折窗单元各至少一个事件；
3. 7、30、90 天跨折信息增益点估计全部为正；
4. 三个滚动折至少 2 折宏信息增益为正，折中位数为正，总体宏信息增益的家族 95% 同时下界大于 0；
5. 第 5 节 `B1/B2` 单步配对 `maxT` 校正后的时间置乱和空间置乱单侧 Monte Carlo `p_adj`
   都不高于 0.05，任一置乱失败率不得超过 1%；
6. 在 600,000 平方公里下严格召回提高至少 5 个百分点，且家族 95% 同时下界大于 0；
7. 至少两个有事件的预冻结区域贡献为正，移除最大贡献区后宏信息增益点估计仍为正。

同召回面积曲线仍按 0 至 960,000 平方公里、每 625 平方公里一个预算点、完整格前缀且不插值计算，
但只作描述，不能替代固定 600,000 平方公里主门。600,000 平方公里约占研究区 6.4%。

`B2` 还必须满足 `B2-B1` 至少 2/3 折为正且折宏中位数为正。若这项失败，只否定动态轨迹；
只要 `B1` 自身通过上述全部共同门，Stage 4A 仍可选择 `B1` 进入独立验证。去最大贡献区的 95%
区间必须报告，但考虑至少 20 个事件分散于 39 个区的功效限制，本开发门只使用其点估计；若不足两个
有事件区域则归为证据不足。

全研究区全部目标始终作为严格召回分母；落在局部不支持区的目标计作漏报，不能通过缩小分母制造提升。

## 8. 四种机器状态与科学结局

先分别按 `invalid > evidence_insufficient > failed > passed` 判定 `B1/B2` 候选，再按采用矩阵
形成全局状态；不能让未采用候选的较差状态覆盖已经合法通过的候选：

- `invalid`：泄漏、目标派生设计、共享身份或 seal 不一致、共享主输出非有限、`B0/C0` 无效，
  或 `B1` 无法拟合/评分。它不自动获得科学价值分类，必须先做根因复审；代码或身份改变必须关闭
  attempt 并另立目标盲协议，不能假装恢复。`B2` 单独无效不使整体 `invalid`，但会使完整候选族
  无法评价，因此整体为 `evidence_insufficient`，不允许改成只评价 `B1`。
- `evidence_insufficient`：事件并集少于 20、任一折窗 0 事件、必需区间无法计算、点阈值达到但
  95% 区间仍包含无改善、置乱失败率超过 1%，或不足两个有事件区域。
- `failed`：运行有效且样本充分，但方向/跨折、任一置乱 `p`、固定面积 +5 pp、覆盖控制外增量或
  跨区点稳健门未通过。
- `passed`：至少一个候选通过全部共同门；`B2` 只有再通过动态轨迹门才优先采用，否则采用通过的
  `B1`。

任一候选可采用则整体 `passed`。`B2` 单独无效时整体固定为 `evidence_insufficient`；无人可采用
且任一可评价候选仍证据不足时也同样如此。只有两个候选均有效、证据充分且无人可采用时，整体才是
`failed`。

### `passed`

- 阶段科学价值：`direct_improvement`，但证据范围只限开发滚动折；
- 可说：发现了值得一次独立验证的异常增量线索；
- 不可说：G2/G3 已正式通过、已经实现可靠地震预测、超过了 ETAS；
- 下一步：只允许先冻结阶段 4B 独立验证协议和代码。

### `failed`

- 阶段科学价值：`no_material_progress`；
- 结论：当前冻结的 `B1/B2` 都没有提供稳定且有实际意义的覆盖控制外增量；
- 动作：保留 KDE，停止异常模型扩张，复审异常时效、空间支持、报告制度和模型组合。

### `evidence_insufficient`

- 阶段科学价值：对预测效果为 `no_material_progress`；
- 结论：样本或合法置乱不足以判断，不把不显著说成无效，也不把点估计说成有效；
- 动作：停止模型扩张，等待新的成熟前瞻样本或调整科学问题；不得在同一开发数据上换规则重试。

纯电源或进程中断只有在协议、代码、输入、随机、ledger 和 checkpoint 身份完全不变时才可恢复同一
attempt，最多一次。任何代码或身份修复都不能复用已经打开目标的 attempt；`invalid` 也不能预先写成
`necessary_enabler`。

## 9. 资源和展示

运行时先检测物理核心数；少于 3 个时失败关闭，否则
`effective_workers=max(1,min(6,physical_cores-2))`。数值库每进程 1 线程，进程优先级为
`BelowNormal`，并把物理/逻辑核心数、worker 数、BLAS 环境变量和优先级写入 receipt。本门默认
CPU float64；只有代码标签前已经证明数值等价的 GPU 路径才能启用，不能为使用 GPU 另建后端而延迟
科学检验。

三个页面的职责严格分开：

1. **公开目标盲历史/开发重放页**：显示起报时刻、7/30/90 天、相对强度、600,000
   平方公里报警层和支持状态；物理上禁止加载目标、命中、漏报和未来事件数字。空间只发布无坐标
   tooltip、无可下载数组的栅格化概化图。Stage 4A 通过时主层只能是选中的 `B1/B2`，`B0`
   可作对照；失败或证据不足时主层回退 `B0`，`B1/B2` 只能默认关闭并标“未采用/仅诊断”；
   `invalid` 时不发布。该页必须标明“目标盲历史/开发重放，不是前瞻证据”，不能称为真正预测。
2. **公开聚合结果页和静态图**：显示最终状态、采用候选、失败门和科学价值决定，以及四模型、
   置信区间（家族同时区间与边际诊断区间明确区分）、两类置乱分布、`B1/B2` 各自的时间/空间
   `maxT p_adj`（裸 `p` 醒目标为仅诊断）、
   固定面积召回、完整面积—召回曲线、Molchan 漏报率—报警时空占比曲线、跨折/跨区、
   每折/窗口事件数与曝光数、成熟截止、全区分母、unsupported 漏报数、特征组系数和敏感性；
   不含原始行、ID 或坐标。两者还必须用外行语言显示数据与方法流程：2019-12-31 截止只限定
   冻结空间 KDE；各折截止前的地震曝光只拟合该折 rate head；评估期 M5–6 地震只用于评分和
   命中/漏报；另显示 205 个因果快照/3,217,885 特征行、覆盖控制、M5–6 边界、三折 × 三窗、
   `B0→C0→B1→B2` 和禁用的人工预测字段，并把源库总量与各折实际入模/评分子集及未来/验证
   保留原因分开。静态图与聚合页必须包含同一组科学字段，不能只展示最好结果。
3. **本地历史回溯页**：可加载历史目标、命中、漏报、失败案例和逐起报钻取，但必须 Git-ignored，
   并醒目标注“历史回溯，不是真正预测”。

本地另保留精确 25 km、仍不含目标的历史/开发重放页，同样不构成前瞻证据。所有 Stage 4A 页面必须
显示“研究开发版本，非业务预警”和“相对条件强度，不是绝对发震概率”。公开结果页的固定
`index.html` 在结果标签冻结后不可覆盖。

只有 Stage 4A 结果标签形成并冻结选中候选或 `B0` 回退后，按当时真实数据截止、在目标窗口开始前
按时生成并不可变归档的 issue 才称为前瞻预测。每个 issue 必须记录 issue/生成时间、数据截止、
7/30/90 天窗口、输入清单哈希、模型身份与 payload 哈希、协议配置哈希、代码提交/标签/seal 哈希和
不可变归档路径；不得含目标、命中/漏报或未来事件数。未来正式起报写入独立日期/issue 目录，只能
追加归档，不能回填，也不能根据后来是否命中覆盖或删除。

信息增益的外行含义是“模型给真实地震位置分配的相对强度，扣除全国总强度后，平均比背景好多少”；
`+5 pp` 例如是严格召回从 20% 提到至少 25%，不是相对增加 5%；置乱 `p` 是假异常达到同样好结果的
频率，不是发震概率。

Molchan 图只作描述，不参与通过门。它在与面积—召回曲线相同的 0 至 960,000 平方公里完整格前缀
上计算：每个折—窗口的纵轴为 `1-全研究区严格召回`，unsupported 目标计漏报；横轴为所有起报曝光的
“实际入选面积 × 窗口时长”之和除以“研究区面积 × 相同曝光总时长”。九个折—窗口单元仍各占
`1/9`，端点固定为零预算 `(alarm_fraction=0, miss_rate=1)`，不插值且不外推超过 960,000
平方公里的部分。

## 10. 每阶段强制科学价值复审

结果形成后，验收和当前重启交接必须立即写入同名字段：

- `science_value_category`
- `evidence`
- `decision`
- `next_scientific_test`
- `stop_condition`

缺少任一字段，阶段不得标记完成、不得提交为下一阶段授权。测试数、代码量、界面完整度和运行稳定性
只能证明工程质量，不能证明预测效果。若没有直接改善，也不能在紧邻下一步转化为一次有限科学检验，
必须停止工程扩张并调整路线。
