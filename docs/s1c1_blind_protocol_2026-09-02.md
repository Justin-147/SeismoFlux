# S1-C1 因果局部目录完整度盲协议（2026-09-02）

## 一句话说明

S1-C0已经看到：在相同600,000 km²报警面积下，利用历史地震空间分布的L2、L3比可解释的区域常率L1
多找到了若干独立目标震序。S1-C1只回答一个问题：**这个提升会不会只是某些地方小地震记录不全造成的假象？**

本协议在查看任何S1-C1新诊断、新预测或新成绩之前冻结。它不是重新设计模型，也不是扩大工程范围；只给训练
目录加一个因果、局部、对所有主模型公平一致的完整度资格掩码。

对应机器可读配置：`configs/multitask_s1_c1_local_completeness.yaml`。

## 1. 什么保持不变

为了只检验“局部目录完整度”这一项，以下内容全部沿用S1-C0，不得借S1-C1之名修改：

- 四个开发年代折：2000–2004、2005–2009、2010–2014、2015–2019；
- 147个M5–6目标震序，以及“首个地震固定为锚点、之后30天和75 km内归为同一震序”的定义；
- 全国研究区、全国评分分母和25 km预测网格；
- 周四00:00起报、24小时目录延迟，以及7/30/90/180/365天时长；
- 30天、600,000 km²、严格命中为主科学检验；
- L1、L2、L3、M0的模型形式、候选参数、三个内层块、选择规则、时间禁运和回退规则；
- L1的1/5/10年候选，L2的75/100/150/200/300 km候选，L3的0/0.25/0.5/0.75候选；
- 固定75 km的`L2_KDE75_LEGACY`连续性参考与其他地点模型使用同一完整度过滤；
- 所有报警面积、折、目标、指标和模型数，不追加任何参数。

冻结的S1-C0未过滤版本只作为敏感性对照，不能单独据此选冠军或打开留出数据。S1-C0中负二项时间模型T1
没有稳定增益，因此本轮停止该方向，不用时间模型调参分散科学问题。为保持既有NPZ和schema兼容，T0、T1
可以按C0原规则机械生成，但不参与C1调参或科学门。M3保持不变；M0使用局部过滤后的训练事件，其影响只在
完全相同的评分事件上作诊断，不作为C1选模或过门依据。

## 2. 怎样避免看到未来

完整度地图不在每个起报日反复估计，而只在两个预定节点生成：每个内层块的起点、每个外层折的起点。每张
快照只能读取该节点前24小时已经发生且已经可获得的目录，随后在整个块或折内冻结，不能用块末、折末或目标
发生后的信息回填。

块或折内每个实际起报日仍可把普通训练历史扩展到“该起报日前24小时”，但必须套用所属块或折在起点冻结的
资格掩码。通俗地说：**历史可以随时间正常增加，但判断哪些地区的M4记录可信，不能看到后来的地震后再改。**

S1地点模型和M0的历史起点继续固定为北京时间`1970-01-01 00:00:00+08:00`，不因本轮完整度处理而
提前、后移或从不同起点挑选数据。

时间完整度可以同时生成不含成绩的诊断说明，但不改变本轮空间训练中心资格规则，也不能把旧方案的全局时间
Mc硬失败或“只在支持区归一、只在支持区评分”搬进来。

## 3. 局部 Mc 怎样估计

目录事件投影到项目已经冻结的中国Albers等面积坐标系，网格原点固定为(0, 0)米。先使用500 km固定格；
内部边界按半开区间归到较高索引格，不根据震中、目标或成绩移动网格。

每个有至少200个可见历史事件的500 km格，用0.1级震级分箱求最大曲率峰值，再加0.2级得到原始Mc；
分箱峰值并列时选较高震级。500 km格不足200个事件时，只能继承与其同一零原点对齐的固定1000 km父格
估计。若父格仍不足200个事件，该500 km格标为`indeterminate`（无法判断），绝不宣称它“完整”。

500/1000 km是本研究事先冻结的支持尺度，用来在全国目录的空间分辨率与至少200事件的稳定性之间取一个固定
折中；它们不是文献规定的唯一正确尺度，也不会冒充高分辨率局地Mc地图。

## 4. Mc 只影响哪里

当一个500 km格自身或继承父格的原始Mc大于4时，只把**该500 km格里的训练事件**从L1、L2、固定75 km
连续性参考L2、L3和M0的训练中心中排除。它不影响相邻格，更不能删除该地区的预测网格、真实目标或评分机会。
这些模型共享完全相同的训练资格，防止一个模型因为“看了更多地震”而占便宜。

父格仍稀疏的`indeterminate`格，在主分析中按事先冻结的“共同Mc=4假设”保留，但必须明确标注这只是
假设，并另做一次“排除所有indeterminate格训练中心”的敏感性分析。无论哪种分析，全国归一、全国评分域和
147个目标分母都不变。

主分析和敏感性分析是两个不可混写的冻结运行：

- `multitask-s1-c1-main-common-mc4-v1`：保留`indeterminate`格，明确采用共同Mc=4假设；
- `multitask-s1-c1-sensitivity-exclude-indeterminate-v1`：排除所有`indeterminate`格的训练中心。

二者必须使用不同输出根、分别封存预测与成绩，禁止跨运行复用或覆盖文件。

## 5. 先过覆盖门，再允许评分

每张快照都计算真正有证据支持的训练面积：只有能够从500 km格或1000 km父格估计Mc、且原始Mc不高于4
的500 km格才算支持区。用这些格与全国研究区的精确等面积交集除以全国总面积，得到支持比例。

只要任一快照低于95%，主检验就在读任何模型成绩之前记为`evidence_insufficient`并停止。此时不能靠缩小
全国范围、删除难预测目标、增加报警面积或追加参数来“救成绩”；应回到科学方案层面决定下一项更有价值的数据
或方法。

## 6. 怎样判断是否值得继续

主比较仍是L2相对L1、L3相对L1，在相同600,000 km²报警面积下的独立目标震序召回差。通过条件沿用C0：

1. 四折合并方向为正；
2. 至少2/4个年代折方向为正；
3. 不增加报警面积；
4. 去掉最大震序，或去掉按固定零原点500 km格定义的最大地区后，方向不能完全反转。

“近期30天是否在长期L2之上再增益”单独检验L3−L2：四折合并必须为正、至少2/4折为正，且去掉最大震序
或最大固定500 km地区后不能完全反转。若这道门失败，只停止R30近期分量，不否定L2或整个地点模型方向，也
不再为R30追加参数。

小而稳定的提升可以作为科学进展，不要求夸张的工程指标；但混合、近零或不稳的方向意味着停止这一模型分支，
不能继续堆参数。即使通过，也只说明局部完整度控制后仍有开发期信号，不等于选出了冠军，更不授权读取holdout、
audit或locked test。

L0均匀模型在报警面积曲线上只报告“报警面积/全国面积”的解析期望。其固定并列前缀来自网格排序，不当作随机
猜测，也不用它的固定前缀置信区间支撑科学结论。L0的均匀空间密度仍可保留作规范评分参考。

## 7. 必须按顺序执行

1. **协议闭合：** 本配置和本文档先完成检查、验收、提交、推送和远端回读；此时禁止预测和评分。
2. **无成绩支持诊断：** 只生成各块/折起点的因果Mc、资格掩码、面积覆盖和合成测试；不得生成预测或读取成绩。
   诊断也必须单独验收、提交、推送和远端回读。
3. **预测并封存：** 覆盖门通过后，按原四折和原模型生成预测；主分析与排除`indeterminate`敏感性使用两个
   独立运行ID和输出根，在读取外折目标和成绩前分别封存四折文件与哈希。T0/T1若因文件格式兼容存在，只能
   按C0原样机械生成，不进入C1调参或科学门。
4. **封存后评分：** 两个运行各自四折封存全部核验通过后才评分，并立即复审它是否真正推动“受控报警面积下提高独立物理
   地震区域召回”。

全程禁止读取或运行2020–2022 holdout、2023+ audit和locked test；禁止改模型、折、目标、时长、面积、
指标和参数；禁止触碰`science_first`既有Stage4未跟踪草稿。大型任务最多3个折线程、数值库单线程，并至少
保留2个物理核心。

## 8. 经典方法依据与本研究取舍

- Wiemer与Wyss（2000）用震级—频度分布讨论目录最小完整震级及其空间差异；本研究据此把Mc视为需要局部
  检查的目录属性，而不是全国一个永恒常数。DOI：[10.1785/0119990114](https://doi.org/10.1785/0119990114)。
- Woessner与Wiemer（2005）比较Mc估计及不确定性，说明单一估计法并非绝对真值；因此本研究使用简单保守的
  MAXC+0.2作主规则，而不在看成绩后换方法。DOI：[10.1785/0120040007](https://doi.org/10.1785/0120040007)。
- Mignan与Woessner（2012）的CORSSA综述系统说明MAXC等目录完整度方法的优缺点；本研究据此把稀疏地区标为
  无法判断，并保留敏感性分析。DOI：[10.5078/corssa-00180805](https://doi.org/10.5078/corssa-00180805)。
- Mignan等（2013）专门研究中国大陆目录完整度与地震预测检验区设置，支持在中国目录上显式考虑时空完整度；
  但本文的500/1000 km与200事件仍是SeismoFlux为本次单因素检验冻结的尺度，不声称来自该论文的唯一标准。
  DOI：[10.1785/0120120052](https://doi.org/10.1785/0120120052)。

这四项经典工作提供的是“为什么要检查、有哪些成熟方法和局限”的依据；具体尺度、因果快照、95%面积门和模型
公平规则，是为本研究目标预先写死的可检验选择。
