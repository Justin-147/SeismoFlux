# S3-A：异常报告能否增加地点与时间信息

日期：2026-09-03。机器协议：`configs/multitask_s3_anomaly.yaml`。当前是评分前方案，
不是新效果；协议完成必要验收、提交和远端确认后才读取本轮目标。旧D1结果保留，不重新包装成新发现。

## 1. 通俗解释与本轮边界

长期地震目录告诉我们哪里本来就容易发震。这次检验：报告中某类异常的新增、积累和变化，
能否进一步指出“这段时间更值得关注的地方”，以及“未来一段时间总体地震活动会不会增加”。
分别比较目录、目录加报告覆盖、再加异常快照、最后加异常变化；不把报告数量本身误认成前兆。

现有资料是异常报告，不是连续仪器原始振幅。四学科计数是带距离权重的已报告异常实体数；
年龄不是确认的持续时长，未续报不等于物理异常结束，学科熵反映共存而不是同步变化。
缺报保持未知，禁用人工预测地点/时间/震级和事后效能字段。

已有库共205期、59,904条观测；**本轮只读2022-07-01至2025-07-01前的合法报告**，
每外折再按自己的截止限制，不是全205期都参与。实际可用数量由首轮水位统计给出，不预填成205。
地震历史仍从1970年累积，不因异常只有几年而截短目录。两个本地目录沿用用户声明的Ms原数值。

## 3. 数据切分和训练

外层开发期固定为2023-07—2024-07和2024-07—2025-07。它们不是盲测；部分日历与C审计重合，
事件一旦用于A开发，不能换个角色名称又声称全流程未见。A的2025-07以后审计、C留出/审计评分和
锁定测试继续关闭。按实际报告可用时刻T起报，目录只看到Q=T−24h。

训练标签的完整窗口终点和可用时刻均不晚于内层/外层开始前30天。训练起报贪心相隔至少h天，
减少重复标签；主评价相隔至少h+30天，与S0保持一致。这不是独立性的保证，仍按震群/时间块报告
不确定性。全部合法报告另作描述性回放，不能以网格数或重叠窗口数量夸大样本。

内验证日历预定为2023-01—06、2023-07—2024-01、2024-01—06，每折只用外评价前的块。
λ仅0.1、1、10，有至少两个可评价内块才选择；否则固定10，不另开时间边界搜索。
第一外折只有一个内块，因此不选λ。这是短历史下的收缩选择，不是宣布第一折失败。
长窗口没有完整训练/评价时记NA，不缩短窗口、不补零，也不据此否决长期异常价值。

16个原始值和4个缺失控制严格组成COV5、SNAP16、DYN20三个嵌套设计，精确列名见机器协议。
计数/年龄log1p，三条变化asinh，其余原尺度；填补和标准化只用相应训练层。
全国计数头用上述网格特征的实际面积均值，不使用真实震中决定权重。

## 4. 同一模型族的两个输出

地点头：q(c|T,h) ∝ p0(c|T,h) exp(βᵀz(c,T))，按每个Ms4+事件的条件空间损失加ridge拟合。
q是全国各格的相对质量，需除格点实际面积作强度排序，不能叫绝对发震概率。
正式Ms[5,6)与Ms≥6分别评价；把Ms4拟合用于两大震带是位置迁移假设，不是震级预测已改善。

p0迁移C2B最新旧开发折的已冻多尺度参数：7/30/90/180天K25/K75/K150权重为0.5/0.5/0，
365天各1/3。参数学习标签不晚于2014-12-02；按新的A起报重新积累此前目录，不复制旧C预测数组。
固定长期/近期75km R30为额外参照。S2静态快照的描述性最佳组合不冒充严格历史来源，留待S5组合。

时间头：μ_b(T,h)=μ0_b(T,h) exp(a+βᵀz全国(T))，μ表示未来完整h天的期望次数。
μ0用1970—Q已知同震级带事件数/历史天数乘h；直接以Ms5+总次数、含零事件窗的Poisson损失训练。
两正式震级共享乘子，次数可加，但不学习两震级比例；不声称完成震级分布改进。
保留未校准目录T0、仅截距校准T0_CAL、覆盖、快照、动态各层，以免校正长期率偏差被归因异常。

计数头仅惩罚β，不惩罚a。全零计数时有限截距MLE不存在，预定回退T0并明确标状态；无合法训练、
拟合不可评价同样登记，不叫“异常零增益”。不造伪计数、不给概率裁剪制造可评价结果。

## 5. 置乱对照的合法角色

时间与空间各200复本/折，规模沿用S0。它们是离线归因对照，不是可发布的预测。
时间置乱按整期联合移动9个快照值及两条radius基础序列，从伪历史重新算三条变化；
覆盖4值及覆盖缺失控制保持原接收方。每折、每h的来源池仅限合法开发报告，并在所有内/外块边界、
实际最后合法训练起报（开始−30d−h）及验证起报终点切段，端点明确归属，禁止跨拟合/验证侧搬运。
切段单例保持不动并报告有效置乱量；不得为增加随机性移动边界。

同段允许晚来源移动到早伪时刻，这是明确的反事实例外，**不得进入真实特征或宣称时间因果预测**。
不调用旧D1完整205期加载器，不用2025-07以后的报告。旧D1确有这种离线例外，不能因“前缀重算”
便误称真实来源满足因果，也不能将旧许可自动扩大到新数据范围。

空间置乱仅在同一期、同静态构造区及inside/outside层内双射实体坐标对，保留实体属性，重算9快照、
两条基础序列、三动态及相应缺失。时间快照缺失随donor走；空间年龄/熵缺失按新支持重算。
每复本重新填补、标准化、选λ、拟合。失败不删掉/另抽替代；报告失败和可解释边界。
覆盖固定不等于完整条件联合分布保留，置乱会破坏自相关或实体连续性；80%位置只作探索证据，
不是精确p值或通用采用门。

## 6. 怎样判断值得继续

全部外折预测先保存，再统一看成绩。地点报同实际报警面积下原始首震锚点命中/漏报及空间评分；
时间报含空窗的Poisson分数、Brier、次数偏差和可靠性。主看动态比覆盖、动态比快照的增量，
同时保留相对目录的正负变化，分7/30/90/180/365天、两震级、地区和首震/后续。
95%区间是统计不确定性，不是已取消的95%全国支持门。小而合理的任务专用改善可保留，
没有增量则结束本变体，不无休止调参。真成绩出炉后输出聚合静态图、好的与失败震例、本机离线回放。

这是S3-A的200km有限起点，不宣称完成整个S3。后续其他尺度和学科消融按S3-B预定有限方案执行，
不能因这次外分数而回调当前模型。S4有限树/小网络、S5组合消融、S6成果整理、S7独立检验仍在路线中。
本次工作属于必要使能，尚无新的真实效果；范围限定为能紧接真实比较的薄实现，不另建数据平台。
