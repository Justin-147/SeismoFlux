未使用人工预测地点/震级/时间、断层与长期危险性快照、旧模型成绩、锁定测试、树模型或神经网络。

`docs/ALL_DATA_SCIENTIFIC_INVENTORY_2026-07-31.md`冻结；D1只取其中能合法进入短期历史回放的子集。

## 2. 怎样防止偷看未来

- 预测输入必须满足`origin_time <= T`且`available_at <= T`；未来目标另按`(T,T+h]`从冻结目录读取。
- 三个外推折按起报时刻切开，拟合issue不晚于评估起点前90天；30/90天曝光在完整时间轴上机械
  取不重叠窗口，不在折边界重置。
- 预处理、缺失填补、尺度、近期权重和ridge只在每折训练内部选择；外层M5–6不能参与选参。
- 震群、代表和身份在看模型成绩前冻结；报警格由相对强度排序，真实震中不得生成网格或候选区。

## 4. 看哪些线索、比较什么模型

九个预定义科学组为：报告相对完整度`C1`、报告广度`C2`、可靠异常负荷`S1`、新出现异常`S2`、
未继续异常`S3`、学科多样性`S4`、空间集中度`S5`、当前异常动量`D1`和新异常动量`D2`。
全零、恒定、确定性重复、高缺失或物理方向含糊的字段已在不看目标的情况下剔除或降为一次敏感性。

冻结的六模型是`B0`、`B0_R30`、`B0_C`、`B0_C_A_snapshot`、`B0_C_A_dynamic`和
`B0_R30_C_A_dynamic`。独立审计发现普通Poisson会把“某期总地震数”混入空间系数，已在评分前
改为逐issue条件空间似然；它直接学习有限报警面积该画在哪里，与最终科学目标一致。
